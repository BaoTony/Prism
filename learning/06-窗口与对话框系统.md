# HandyControl 深度学习 - 窗口与对话框系统

## 🪟 窗口系统总览

HandyControl 对 WPF 的 `Window` 进行了深度定制，提供了无标题栏自定义窗口、弹出窗口、消息框、发光窗口、模糊窗口等多种窗口变体，同时实现了基于 Adorner 层的轻量级对话框系统和消息提醒机制。

### 窗口类继承关系

```
System.Windows.Window
  ├── HandyControl.Controls.Window              # 自定义窗口基类
  │     ├── HandyControl.Controls.MessageBox    # 消息框（sealed）
  │     ├── HandyControl.Controls.BlurWindow    # 模糊窗口
  │     ├── HandyControl.Controls.GlowWindow    # 发光窗口
  │     └── HandyControl.Controls.ImageBrowser  # 图片浏览器
  │
  └── HandyControl.Controls.PopupWindow         # 弹出窗口

System.Windows.Controls.ContentControl
  └── HandyControl.Controls.Dialog              # 覆盖层对话框

System.Windows.Controls.Control
  └── HandyControl.Controls.Growl               # 消息提醒
```

## 🪟 [Window.cs](../src/Shared/HandyControl_Shared/Controls/Window/Window.cs) - 自定义窗口

### 核心特性

- 完全自定义的非客户区（标题栏、控制按钮）
- 支持 Windows 11 原生圆角
- 非客户区可放置任意内容
- 全屏支持

### TemplatePart

```csharp
[TemplatePart(Name = ElementNonClientArea, Type = typeof(UIElement))]
public class Window : System.Windows.Window
{
    private const string ElementNonClientArea = "PART_NonClientArea";
}
```

### 关键依赖属性

| 属性 | 类型 | 说明 |
|------|------|------|
| `NonClientAreaContent` | `object` | 非客户区内容（标题栏自定义内容） |
| `NonClientAreaHeight` | `double` | 非客户区高度 |
| `ShowNonClientArea` | `bool` | 是否显示非客户区 |
| `CloseButtonHoverBackground` | `Brush` | 关闭按钮悬停背景 |
| `CloseButtonHoverForeground` | `Brush` | 关闭按钮悬停前景 |
| `CloseButtonBackground` | `Brush` | 关闭按钮背景 |
| `OtherButtonHoverBackground` | `Brush` | 其他按钮（最小化/最大化）悬停背景 |

### 构造函数 - WindowChrome 配置

```csharp
public Window()
{
    var chrome = new WindowChrome
    {
        UseAeroCaptionButtons = false  // 禁用 Aero 标题按钮，使用自定义按钮
    };

    // Windows 11 22H2 以下版本需要手动设置边框
    if (SystemHelper.GetSystemVersionInfo() < SystemVersionInfo.Windows11_22H2)
    {
        chrome.GlassFrameThickness = new Thickness(0, 0, 0, 1);
        chrome.CornerRadius = new CornerRadius();
    }

    // 将 CaptionHeight 绑定到 NonClientAreaHeight
    BindingOperations.SetBinding(chrome, WindowChrome.CaptionHeightProperty,
        new Binding(NonClientAreaHeightProperty.Name) { Source = this });

    WindowChrome.SetWindowChrome(this, chrome);
}
```

**设计要点：**
- 使用 `WindowChrome` 实现自定义非客户区
- 通过 `SystemHelper.GetSystemVersionInfo()` 检测 Windows 11 22H2+，自动使用原生圆角
- `CaptionHeight` 绑定到 `NonClientAreaHeight`，使自定义标题栏支持拖拽移动

### 使用示例

```xml
<hc:Window x:Class="MyApp.MainWindow"
           xmlns:hc="https://handyorg.github.io/handycontrol"
           Title="自定义窗口"
           Height="500" Width="800">
    <hc:Window.NonClientAreaContent>
        <!-- 自定义标题栏内容 -->
        <StackPanel Orientation="Horizontal" VerticalAlignment="Center">
            <TextBlock Text="MyApp" Margin="10,0" VerticalAlignment="Center"/>
        </StackPanel>
    </hc:Window.NonClientAreaContent>

    <Grid>
        <!-- 窗口内容 -->
    </Grid>
</hc:Window>
```

## 📦 [Dialog.cs](../src/Shared/HandyControl_Shared/Controls/Dialog/Dialog.cs) - 覆盖层对话框

Dialog 是 HandyControl 中最独特的对话框实现：**它不是 Window，而是 `ContentControl`**，通过 WPF 的 `AdornerLayer` 叠加在目标元素之上。

### 设计优势

| 特性 | Dialog (Adorner) | PopupWindow (Window) |
|------|-----------------|---------------------|
| 创建新窗口 | ❌ 否 | ✅ 是 |
| 任务栏图标 | ❌ 无 | ✅ 有 |
| 模态阻塞 | ✅ 是（禁用父元素） | ✅ 是（ShowDialog） |
| 性能 | 高（无新句柄） | 较低 |
| 可定位到容器 | ✅ 任意元素 | ❌ 只能定位到屏幕 |

### TemplatePart

```csharp
[TemplatePart(Name = BackElement, Type = typeof(Border))]
public class Dialog : ContentControl
{
    private const string BackElement = "PART_BackElement";
}
```

### 关键属性

| 属性 | 类型 | 说明 |
|------|------|------|
| `IsClosed` | `bool` | 是否已关闭 |
| `MaskBrush` | `Brush` | 遮罩层画刷 |
| `MaskCanClose` (附加) | `bool` | 点击遮罩是否可关闭 |
| `Token` (附加) | `string` | 令牌，用于关联 DialogContainer |

### Show 方法 - 核心逻辑

```csharp
public static Dialog Show(object content, string token = "")
{
    var dialog = new Dialog
    {
        _token = token,
        Content = content
    };

    FrameworkElement element;
    AdornerDecorator decorator;

    if (string.IsNullOrEmpty(token))
    {
        // 无令牌：显示在当前激活窗口上
        element = WindowHelper.GetActiveWindow();
        decorator = VisualHelper.GetChild<AdornerDecorator>(element);
    }
    else
    {
        // 有令牌：显示在关联的 DialogContainer 上
        Close(token);
        DialogDict[token] = dialog;
        TokenManager.TryGetControl(token, out element);
        decorator = element is System.Windows.Window
            ? VisualHelper.GetChild<AdornerDecorator>(element)
            : VisualHelper.GetChild<DialogContainer>(element);
    }

    if (decorator != null)
    {
        // 禁用底层内容
        if (decorator.Child != null)
            decorator.Child.IsEnabled = false;

        // 将 Dialog 添加到 AdornerLayer
        var layer = decorator.AdornerLayer;
        var container = new AdornerContainer(layer) { Child = dialog };
        dialog._container = container;
        dialog.IsClosed = false;
        layer.Add(container);
    }

    return dialog;
}
```

### Close 方法

```csharp
public void Close()
{
    if (string.IsNullOrEmpty(_token))
    {
        Close(WindowHelper.GetActiveWindow());
    }
    else if (TokenManager.TryGetControl(_token, out var element))
    {
        Close(element);
        DialogDict.Remove(_token);
    }
}

private void Close(DependencyObject element)
{
    var decorator = VisualHelper.GetChild<AdornerDecorator>(element);
    if (decorator != null)
    {
        // 恢复底层内容交互
        if (decorator.Child != null)
            decorator.Child.IsEnabled = true;

        // 从 AdornerLayer 移除
        decorator.AdornerLayer?.Remove(_container);
        IsClosed = true;
    }
}
```

### 遮罩点击关闭

```csharp
protected override void OnMouseLeftButtonUp(MouseButtonEventArgs e)
{
    if (GetMaskCanClose(this) && _backElement is { IsMouseDirectlyOver: true })
    {
        Close();
    }
}
```

## 🔐 Token 机制 - 控件关联

HandyControl 的 Dialog、Growl、NotifyIcon 等控件都使用 **Token 机制** 来关联容器。

### 原理

通过 `ControlTokenManager<T>` 管理 Token 与控件的映射：

```csharp
internal class ControlTokenManager<T> where T : FrameworkElement
{
    private static readonly Dictionary<string, WeakReference> TokenDict = new();

    public static void OnTokenChanged(DependencyObject d, DependencyPropertyChangedEventArgs e)
    {
        // Token 变化时，注册/注销控件
    }

    public static bool TryGetControl(string token, out T control)
    {
        // 从字典查找
    }
}
```

### 使用流程

```
1. 在容器上设置 hc:Dialog.Token="MyToken"
2. 容器加载时，TokenManager 记录 Token → 容器 的映射
3. 调用 Dialog.Show(content, "MyToken") 时
4. TokenManager 根据 "MyToken" 找到容器
5. Dialog 显示在该容器的 AdornerLayer 中
```

### 优势

- **解耦**：显示方不需要持有容器引用
- **灵活**：可在任意位置显示
- **多实例**：不同 Token 支持多个独立对话框

## 📊 窗口/对话框选型指南

| 场景 | 推荐控件 | 原因 |
|------|---------|------|
| 主应用窗口 | `hc:Window` | 自定义标题栏、主题一致 |
| 简单确认/提示 | `MessageBox` | 开箱即用、返回结果 |
| 模态表单对话框 | `Dialog` | 无新窗口、性能好 |
| 独立工具窗口 | `PopupWindow` | 可拖动、独立窗口 |
| 轻量消息提示 | `Growl` | 自动消失、不阻塞 |
| 富内容通知 | `Notification` | 支持复杂内容和交互 |
| 系统托盘 | `NotifyIcon` | 后台运行、气泡通知 |
| 图片预览 | `ImageBrowser` | 内置缩放/浏览功能 |
| 毛玻璃效果 | `BlurWindow` | 视觉效果突出 |

## ⚠️ 常见问题

### Q1: Dialog 显示后底层控件仍然可点击？

**原因：** 目标元素没有 `AdornerDecorator`，或 `IsEnabled` 设置失败。

**解决方案：**
```xml
<!-- 确保窗口包含 AdornerDecorator -->
<Window>
    <AdornerDecorator>
        <Grid>...内容...</Grid>
    </AdornerDecorator>
</Window>
```

> HandyControl 的 `Window` 模板已内置 `AdornerDecorator`，自定义 Window 模板时需注意。

### Q2: Growl 不显示？

**原因：** 没有设置 `GrowlParent` 容器。

**解决方案：**
```xml
<StackPanel hc:Growl.GrowlParent="True"
            HorizontalAlignment="Right"
            VerticalAlignment="Top"/>
```

### Q3: MessageBox 按钮文字无法修改？

**解决方案：** 使用 `MessageBoxInfo` 的 `Buttons` 属性自定义按钮。
