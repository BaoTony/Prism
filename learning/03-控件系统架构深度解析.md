## 🔧 模板部件机制（TemplatePart）

### 什么是 TemplatePart？

TemplatePart 是 WPF 自定义控件的核心模式，允许控件代码与 XAML 模板进行约定式的交互。

### 工作原理

```
1. 控件类使用 [TemplatePart] 特性声明需要的模板元素
2. XAML Style/Template 中定义对应名称的元素
3. 在 OnApplyTemplate() 中获取这些元素的引用
4. 通过引用操作模板元素（添加事件处理、修改属性等）
```

### 完整示例：[Dialog.cs](../src/Shared/HandyControl_Shared/Controls/Dialog/Dialog.cs)

#### 第一步：声明 TemplatePart

```csharp
[TemplatePart(Name = BackElement, Type = typeof(Border))]
public class Dialog : ContentControl
{
    private const string BackElement = "PART_BackElement";
    
    private Border _backElement;  // 存储模板部件引用
}
```

#### 第二步：在 Style 中定义模板

```xml
<Style TargetType="hc:Dialog">
    <Setter Property="Template">
        <Setter.Value>
            <ControlTemplate TargetType="hc:Dialog">
                <Grid>
                    <!-- 背景遮罩 -->
                    <Border x:Name="PART_BackElement"
                            Background="{TemplateBinding MaskBrush}"
                            Opacity="0.5"
                            MouseDown="BackElement_OnMouseDown"/>
                    
                    <!-- 对话框内容 -->
                    <Border Background="White"
                            CornerRadius="4"
                            Padding="20"
                            Width="400"
                            HorizontalAlignment="Center"
                            VerticalAlignment="Center">
                        <ContentPresenter Content="{TemplateBinding Content}"/>
                    </Border>
                </Grid>
            </ControlTemplate>
        </Setter.Value>
    </Setter>
</Style>
```

#### 第三步：在 OnApplyTemplate 中获取引用

```csharp
public class Dialog : ContentControl
{
    private const string BackElement = "PART_BackElement";
    private Border _backElement;
    
    public override void OnApplyTemplate()
    {
        base.OnApplyTemplate();
        
        // 获取模板部件的引用
        _backElement = GetTemplateChild(BackElement) as Border;
        
        if (_backElement != null)
        {
            // 可以在这里添加事件处理器或进行初始化
            _backElement.MouseLeftButtonDown += OnBackElementClick;
        }
    }
    
    private void OnBackElementClick(object sender, MouseButtonEventArgs e)
    {
        // 处理背景点击事件
        if (GetMaskCanClose(this))
        {
            Close();
        }
    }
}
```

### TemplatePart 命名规范

HandyControl 使用统一的命名约定：

| 前缀 | 用途 | 示例 |
|------|------|------|
| `PART_` | 主要模板部件 | `PART_BackElement`, `PART_ContentHost` |
| `Header_` | 头部相关 | `Header_Element` |
| `Content_` | 内容区域 | `Content_Presenter` |

### 常见 TemplatePart 类型

```csharp
// 边框/背景

// 内容展示

// 滚动视图

// 按钮
```

## 📎 附加属性系统（Attached Properties）

### 什么是附加属性？

附加属性是 WPF 的一种特殊依赖属性，允许为一个对象设置定义在另一个类型上的属性。

### 为什么重要？

HandyControl 大量使用附加属性来**无侵入式地扩展**现有 WPF 控件的功能。

### 典型示例：[InfoElement.cs](../src/Shared/HandyControl_Shared/Controls/Attach/InfoElement.cs)

这个附加类为任何控件添加"标签/提示信息"功能。

#### 定义附加属性

```csharp
public class InfoElement
{
    #region Title - 标题文本
    
    public static readonly DependencyProperty TitleProperty = 
        DependencyProperty.RegisterAttached(
            "Title",                           // 属性名
            typeof(string),                    // 属性类型
            typeof(InfoElement),               // 所有者类型
            new PropertyMetadata(default(string), OnTitleChanged));  // 默认值和回调
    
    public static void SetTitle(DependencyObject element, string value)
    {
        element.SetValue(TitleProperty, value);
    }
    
    public static string GetTitle(DependencyObject element)
    {
        return (string)element.GetValue(TitleProperty);
    }
    
    private static void OnTitleChanged(DependencyObject d, DependencyPropertyChangedEventArgs e)
    {
        // 属性变更时的处理逻辑
        if (d is not FrameworkElement element) return;
        
        if (e.NewValue is string title && !string.IsNullOrEmpty(title))
        {
            // 创建并添加标题元素
            AddTitleElement(element, title);
        }
        else
        {
            // 移除标题元素
            RemoveTitleElement(element);
        }
    }
    
    #endregion
    
    #region TitlePlacement - 标题位置
    
    public static readonly DependencyProperty TitlePlacementProperty =
        DependencyProperty.RegisterAttached(
            "TitlePlacement",
            typeof(TitlePlacementType),
            typeof(InfoElement),
            new PropertyMetadata(default(TitlePlacementType)));
    
    public static void SetTitlePlacement(DependencyObject element, TitlePlacementType value)
        => element.SetValue(TitlePlacementProperty, value);
    
    public static TitlePlacementType GetTitlePlacement(DependencyObject element)
        => (TitlePlacementType)element.GetValue(TitlePlacementProperty);
    
    #endregion
    
    #region 其他属性...
    
    public static readonly DependencyProperty NecessaryProperty = ...;  // 必填标记
    public static readonly DependencyProperty SymbolProperty = ...;     // 符号
    public static readonly DependencyProperty ErrorMessageProperty = ...; // 错误消息
    
    #endregion
}
```

#### 使用附加属性

**XAML 使用：**

```xml
<StackPanel>
    <!-- 为 TextBox 添加标题 -->
    <TextBox hc:InfoElement.Title="用户名"
             hc:InfoElement.TitlePlacement="Top"
             hc:InfoElement.Necessary="True"
             Width="200"/>
    
    <!-- 为 ComboBox 添加标题 -->
    <ComboBox hc:InfoElement.Title="城市"
              hc:InfoElement.Symbol="&#xe739;"
              Width="200">
        <ComboBoxItem Content="北京"/>
        <ComboBoxItem Content="上海"/>
    </ComboBox>
</StackPanel>
```

**C# 代码使用：**

```csharp
var textBox = new TextBox();
InfoElement.SetTitle(textBox, "邮箱");
InfoElement.SetNecessary(textBox, true);
InfoElement.SetTitlePlacement(textBox, TitlePlacementType.Left);
```

### 附加属性的内部实现原理

#### 属性变更回调中的常见模式

```csharp
private static void OnXxxChanged(DependencyObject d, DependencyPropertyChangedEventArgs e)
{
    // 1. 类型检查
    if (d is not FrameworkElement element) return;
    
    // 2. 延迟初始化（避免设计时错误）
    if (!element.IsLoaded)
    {
        element.Loaded += OnElementLoaded;
        return;
    }
    
    // 3. 应用更改
    ApplyChange(element, e.NewValue);
}

private static void OnElementLoaded(object sender, RoutedEventArgs e)
{
    if (sender is FrameworkElement element)
    {
        element.Loaded -= OnElementLoaded;
        var value = GetXxx(element);  // 获取当前值
        ApplyChange(element, value);
    }
}
```

#### 使用 WeakReference 避免内存泄漏

```csharp
private static readonly Dictionary<object, List<WeakReference>> ElementDict = new();

private static void TrackElement(FrameworkElement element, object extraData)
{
    if (!ElementDict.ContainsKey(extraData))
    {
        ElementDict[extraData] = new List<WeakReference>();
    }
    
    ElementDict[extraData].Add(new WeakReference(element));
    
    // 元素卸载时清理
    element.Unloaded += (s, e) => CleanupElement(element, extraData);
}
```

## 🔄 控件生命周期

### 完整的生命周期阶段

```
1. 构造函数 (Constructor)
   ↓
2. 依赖属性初始化 (Dependency Property Initialization)
   ↓
3. 应用样式和模板 (Apply Template)
   ↓
4. OnApplyTemplate() 被调用
   ↓
5. 获取 TemplatePart 引用
   ↓
6. 初始化子控件和事件
   ↓
7. Loaded 事件触发
   ↓
8. 控件可交互 (Interactive State)
   ↓
9. Unloaded 事件触发
   ↓
10. 清理资源 (Cleanup)
```

### 各阶段的最佳实践

#### 1️⃣ 构造函数阶段

```csharp
public MyControl()
{
    // ✅ 可以做的：
    // - 设置默认属性值
    // - 注册事件处理器（如果不需要 TemplatePart）
    // - 初始化非可视化的数据结构
    
    DefaultStyleKeyProperty.OverrideMetadata(typeof(MyControl),
        new FrameworkPropertyMetadata(typeof(MyControl)));
    
    // ❌ 不应该做的：
    // - 访问 TemplatePart（此时模板还未应用）
    // - 操作可视化树
    // - 依赖控件的 ActualWidth/ActualHeight
}
```

#### 2️⃣ OnApplyTemplate 阶段

```csharp
public override void OnApplyTemplate()
{
    base.OnApplyTemplate();  // ⚠️ 必须调用基类方法
    
    // ✅ 正确的做法：
    
    // 获取 TemplatePart
    _partBorder = GetTemplateChild(PartBorder) as Border;
    _partButton = GetTemplateChild(PartButton) as Button;
    
    // 如果获取成功，初始化它们
    if (_partButton != null)
    {
        _partButton.Click += PartButton_Click;
    }
    
    // ❌ 错误的做法：
    // - 不调用 base.OnApplyTemplate()
    // - 假设 TemplatePart 一定存在（可能被自定义模板移除）
    // - 在这里执行耗时操作
}
```

#### 3️⃣ Loaded 阶段

```csharp
public MyControl()
{
    Loaded += OnLoaded;
}

private void OnLoaded(object sender, RoutedEventArgs e)
{
    // ✅ 此时可以安全地：
    // - 访问 ActualWidth/ActualHeight
    // - 执行布局相关的计算
    // - 启动动画
    // - 执行数据绑定相关的初始化
    
    UpdateLayout();
    StartAnimation();
}
```

#### 4️⃣ 清理阶段

```csharp
public override void OnApplyTemplate()
{
    // 先清理旧的引用
    if (_partButton != null)
    {
        _partButton.Click -= PartButton_Click;
    }
    
    base.OnApplyTemplate();
    
    // 获取新的引用
    _partButton = GetTemplateChild(PartButton) as Button;
    if (_partButton != null)
    {
        _partButton.Click += PartButton_Click;
    }
}

// 或者实现 IDisposable
protected virtual void Dispose(bool disposing)
{
    if (disposing)
    {
        // 清理托管资源
        _partButton?.Click -= PartButton_Click;
        _timer?.Stop();
        _timer = null;
    }
}
```

## 🎨 控件开发实战：创建自定义控件

让我们通过一个完整的例子来学习如何开发 HandyControl 风格的自定义控件。

### 示例：RatingControl 评分控件

#### 第一步：定义控件类

```csharp
// RatingControl.cs
using System;
using System.Collections.Generic;
using System.Windows;
using System.Windows.Controls;
using System.Windows.Input;
using System.Windows.Media;
using HandyControl.Data;

namespace HandyControl.Controls;

[TemplatePart(Name = PartItemsContainer, Type = typeof(Panel))]
public class RatingControl : Control
{
    private const string PartItemsContainer = "PART_ItemsContainer";
    
    private Panel _itemsContainer;
    private List<RateItem> _rateItems = new();
    
    #region 依赖属性
    
    public static readonly DependencyProperty ValueProperty = DependencyProperty.Register(
        nameof(Value), typeof(double), typeof(RatingControl),
        new FrameworkPropertyMetadata(0.0, FrameworkPropertyMetadataOptions.BindsTwoWayByDefault, OnValueChanged));
    
    public double Value
    {
        get => (double)GetValue(ValueProperty);
        set => SetValue(ValueProperty, value);
    }
    
    public static readonly DependencyProperty MaxValueProperty = DependencyProperty.Register(
        nameof(MaxValue), typeof(int), typeof(RatingControl),
        new PropertyMetadata(5, OnMaxValueChanged));
    
    public int MaxValue
    {
        get => (int)GetValue(MaxValueProperty);
        set => SetValue(MaxValueProperty, value);
    }
    
    public static readonly DependencyProperty IconProperty = DependencyProperty.Register(
        nameof(Icons), typeof(string), typeof(RatingControl),
        new PropertyMetadata("\ue983"));  // 默认星星图标
    
    public string Icons
    {
        get => (string)GetValue(IconProperty);
        set => SetValue(IconProperty, value);
    }
    
    public static readonly DependencyProperty IconFilledProperty = DependencyProperty.Register(
        nameof(IconFilled), typeof(string), typeof(RatingControl),
        new PropertyMetadata("\ue9cb"));  // 默认实心星星
    
    public string IconFilled
    {
        get => (string)GetValue(IconFilledProperty);
        set => SetValue(IconFilledProperty, value);
    }
    
    #endregion
    
    #region 路由事件
    
    public static readonly RoutedEvent ValueChangedEvent = EventManager.RegisterRoutedEvent(
        "ValueChanged", RoutingStrategy.Bubble,
        typeof(EventHandler<FunctionEventArgs<double>>), typeof(RatingControl));
    
    public event EventHandler<FunctionEventArgs<double>> ValueChanged
    {
        add => AddHandler(ValueChangedEvent, value);
        remove => RemoveHandler(ValueChangedEvent, value);
    }
    
    #endregion
    
    static RatingControl()
    {
        DefaultStyleKeyProperty.OverrideMetadata(typeof(RatingControl),
            new FrameworkPropertyMetadata(typeof(RatingControl)));
    }
    
    public override void OnApplyTemplate()
    {
        base.OnApplyTemplate();
        
        // 清理旧的项目
        ClearItems();
        
        // 获取容器
        _itemsContainer = GetTemplateChild(PartItemsContainer) as Panel;
        
        if (_itemsContainer != null)
        {
            GenerateItems();
        }
    }
    
    private void GenerateItems()
    {
        for (int i = 0; i < MaxValue; i++)
        {
            var item = new RateItem
            {
                Index = i + 1,
                Icon = Icons,
                IconFilled = IconFilled
            };
            
            item.MouseEnter += Item_MouseEnter;
            item.MouseLeave += Item_MouseLeave;
            item.PreviewMouseLeftButtonUp += Item_Click;
            
            _itemsContainer.Children.Add(item);
            _rateItems.Add(item);
        }
        
        UpdateVisualState();
    }
    
    private void ClearItems()
    {
        if (_itemsContainer != null)
        {
            foreach (var item in _rateItems)
            {
                item.MouseEnter -= Item_MouseEnter;
                item.MouseLeave -= Item_MouseLeave;
                item.PreviewMouseLeftButtonUp -= Item_Click;
            }
            _itemsContainer.Children.Clear();
        }
        _rateItems.Clear();
    }
    
    private int _hoverIndex = -1;
    
    private void Item_MouseEnter(object sender, MouseEventArgs e)
    {
        if (sender is RateItem item)
        {
            _hoverIndex = item.Index;
            UpdateHoverState();
        }
    }
    
    private void Item_MouseLeave(object sender, MouseEventArgs e)
    {
        _hoverIndex = -1;
        UpdateVisualState();
    }
    
    private void Item_Click(object sender, MouseButtonEventArgs e)
    {
        if (sender is RateItem item)
        {
            Value = item.Index;
        }
    }
    
    private static void OnValueChanged(DependencyObject d, DependencyPropertyChangedEventArgs e)
    {
        if (d is RatingControl control)
        {
            control.UpdateVisualState();
            control.RaiseValueChanged((double)e.NewValue);
        }
    }
    
    private static void OnMaxValueChanged(DependencyObject d, DependencyPropertyChangedEventArgs e)
    {
        if (d is RatingControl control && control._itemsContainer != null)
        {
            control.ClearItems();
            control.GenerateItems();
        }
    }
    
    private void UpdateVisualState()
    {
        for (int i = 0; i < _rateItems.Count; i++)
        {
            var item = _rateItems[i];
            item.IsFilled = (i + 1) <= Value;
        }
    }
    
    private void UpdateHoverState()
    {
        for (int i = 0; i < _rateItems.Count; i++)
        {
            var item = _rateItems[i];
            if (_hoverIndex >= 0)
            {
                item.IsFilled = (i + 1) <= _hoverIndex;
            }
            else
            {
                item.IsFilled = (i + 1) <= Value;
            }
        }
    }
    
    private void RaiseValueChanged(double newValue)
    {
        var args = new FunctionEventArgs<double>(newValue, ValueChangedEvent);
        RaiseEvent(args);
    }
}
```

#### 第二步：创建子项控件

### 1. 依赖属性的性能优化

#### 使用 ReadOnly 依赖属性

#### 使用 ValidateValueCallback

```csharp
public static readonly DependencyProperty ValueProperty = DependencyProperty.Register(
    nameof(Value), typeof(int), typeof(MyControl),
    new PropertyMetadata(0, OnValueChanged, CoerceValue),
    ValidateValue);

private static object CoerceValue(DependencyObject d, object baseValue)
{
    // 强制值在有效范围内
    var value = (int)baseValue;
    return Math.Max(0, Math.Min(100, value));  // 限制在 0-100
}

private static bool ValidateValue(object value)
{
    // 验证值是否有效
    return value is int intValue && intValue >= 0;
}
```

### 2. 路由事件的正确使用

#### 定义路由事件

```csharp
// 1. 声明路由事件
public static readonly RoutedEvent CustomEvent = EventManager.RegisterRoutedEvent(
    "Custom",                                    // 事件名称
    RoutingStrategy.Bubble,                       // 路由策略（Bubble/Tunnel/Direct）
    typeof(EventHandler<FunctionEventArgs<string>>), // 处理器类型
    typeof(MyControl));                           // 所有者类型

// 2. 提供 CLR 事件包装器
public event EventHandler<FunctionEventArgs<string>> Custom
{
    add => AddHandler(CustomEvent, value);
    remove => RemoveHandler(CustomEvent, value);
}

// 3. 触发事件的方法
protected virtual void OnCustom(FunctionEventArgs<string> e)
{
    RaiseEvent(e);
}

// 4. 便捷的重载
protected void OnCustom(string value)
{
    OnCustom(new FunctionEventArgs<string>(value, CustomEvent));
}
```

#### 路由策略的选择

| 策略 | 方向 | 使用场景 |
|------|------|---------|
| **Bubble** | 从源向上冒泡 | 最常用，如 Click |
| **Tunnel** | 从根向下隧道 | 预览事件，如 PreviewKeyDown |
| **Direct** | 只在源上 | 类似普通 CLR 事件 |

## 🎯 常见问题与解决方案

### Q1: TemplatePart 总是 null？

**原因：** 模板尚未应用或名称不匹配。

**解决方案：**
```csharp
public override void OnApplyTemplate()
{
    base.OnApplyTemplate();  // ⚠️ 不要忘记
    
    var part = GetTemplateChild("PART_MyPart") as Border;
    if (part == null)
    {
        // 记录警告或使用备用方案
        System.Diagnostics.Debug.WriteLine("Warning: PART_MyPart not found in template");
        return;
    }
    // 安全地使用 part
}
```

### Q2: 自定义模板后功能失效？

**原因：** 用户自定义模板缺少必需的 TemplatePart。

**解决方案：**
- 文档中明确列出必需的 TemplatePart
- 对于关键部件，考虑提供 fallback 逻辑
- 使用 VisualStateManager 而不是直接操作 TemplatePart

### Q3: 内存泄漏？

**原因：** 事件处理器未正确注销。

**解决方案：**
```csharp
// 在 OnApplyTemplate 中
if (_oldButton != null)
{
    _oldButton.Click -= Button_Click;  // 先注销旧的
}
_button = GetTemplateChild(PartButton) as Button;
if (_button != null)
{
    _button.Click += Button_Click;  // 再注册新的
}
```

### Q4: 性能问题？

**优化建议：**
- 使用 `VirtualizingStackPanel` 启用虚拟化
- 避免在 `OnApplyTemplate` 中执行耗时操作
- 合理使用 `Freezable` 对象（如 Brush, Geometry）
- 考虑使用 `UIElement.CacheMode`
