# HandyControl 深度学习 - 主题与样式系统深度剖析

## 🎨 主题系统总览

HandyControl 的主题系统是其最核心的特性之一，提供了灵活、可扩展的 UI 外观管理能力。该系统支持亮色/暗色皮肤切换、自定义强调色、以及跟随系统主题等功能。

### 主题系统的核心价值

1. **开箱即用**：内置亮色和暗色两套完整主题
2. **动态切换**：运行时无缝切换，无需重启应用
3. **高度可定制**：支持自定义颜色、字体、图标等
4. **系统同步**：可自动跟随 Windows 系统主题
5. **性能优化**：智能缓存机制，避免重复加载

**为什么继承 ResourceDictionary？**

##### 1. Skin 属性 - 皮肤类型

```csharp
private SkinType _skin;

public virtual SkinType Skin
{
    get => _skin;
    set
    {
        if (_skin == value) return;  // 避免重复设置
        _skin = value;
        UpdateSkin();  // 更新皮肤
    }
}
```

**SkinType 枚举：**

```csharp
public enum SkinType
```

##### 2. SyncWithSystem 属性 - 同步系统主题

```csharp
private bool _syncWithSystem;

public bool SyncWithSystem
{
    get => _syncWithSystem;
    set
    {
        _syncWithSystem = value;

        if (value)
        {
            // 保存当前手动设置的皮肤类型
            _manualSkinType = _skin;
            
            // 立即同步一次
            SyncWithSystemTheme();
            
            // 监听系统主题变化事件
            SystemEvents.UserPreferenceChanged += SystemEvents_UserPreferenceChanged;
        }
        else
        {
            // 取消监听
            SystemEvents.UserPreferenceChanged -= SystemEvents_UserPreferenceChanged;
            
            // 恢复到之前的手动设置
            _skin = _manualSkinType;
            UpdateSkin();
        }
    }
}

private void SyncWithSystemTheme()
{
    // 检测 Windows 系统当前是亮色还是暗色模式
    _skin = SystemHelper.DetermineIfInLightThemeMode() 
        ? SkinType.Default 
        : SkinType.Dark;
    
    UpdateSkin();
}

private void SystemEvents_UserPreferenceChanged(object sender, UserPreferenceChangedEventArgs e)
{
    if (e.Category == UserPreferenceCategory.General)
    {
        SyncWithSystemTheme();
    }
}
```

**使用场景：**
- 希望应用自动跟随 Windows 10/11 的亮色/暗色模式
- 用户在系统设置中切换时，应用自动响应

##### 3. AccentColor 属性 - 自定义强调色

```csharp
private Color? _accentColor;

public Color? AccentColor
{
    get => _accentColor;
    set
    {
        _accentColor = value;
        
        if (value == null)
        {
            _precSkin = null;  // 清除缓存
        }
        
        UpdateSkin();  // 应用新的强调色
    }
}
```

**功能说明：**
- 允许用户自定义主题的强调色（Primary Color）
- 设置为 `null` 时恢复默认蓝色
- 会影响所有使用 PrimaryBrush 的控件

**示例：**

```csharp

var theme = new Theme
{
    Skin = SkinType.Dark,
    AccentColor = Colors.Orange
};

Application.Current.Resources.MergedDictionaries.Add(theme);
```

### 附加属性：SkinProperty

```csharp
public static readonly DependencyProperty SkinProperty = DependencyProperty.RegisterAttached(
    "Skin", 
    typeof(SkinType), 
    typeof(Theme), 
    new PropertyMetadata(default(SkinType), OnSkinChanged));

private static void OnSkinChanged(DependencyObject d, DependencyPropertyChangedEventArgs e)
{
    if (d is not FrameworkElement element) return;

    var skin = (SkinType)e.NewValue;

    // 查找元素资源中的所有 Theme 实例
    var themes = new List<Theme>();
    GetAllThemes(element.Resources, ref themes);

    if (themes.Count > 0)
    {
        // 如果已有 Theme，更新它们的 Skin
        foreach (var theme in themes)
        {
            theme.Skin = skin;
        }
    }
    else
    {
        // 否则添加一个新的 Theme
        element.Resources.MergedDictionaries.Add(new Theme { Skin = skin });
    }
}

// 递归查找所有 Theme 实例
private static void GetAllThemes(ResourceDictionary resourceDictionary, ref List<Theme> themes)
{
    if (resourceDictionary is Theme theme)
    {
        themes.Add(theme);
    }

    // 必须检查 MergedDictionaries
    foreach (var dictionaryMergedDictionary in resourceDictionary.MergedDictionaries)
    {
        GetAllThemes(dictionaryMergedDictionary, ref themes);
    }
}

public static void SetSkin(DependencyObject element, SkinType value)
    => element.SetValue(SkinProperty, value);

public static SkinType GetSkin(DependencyObject element)
    => (SkinType)element.GetValue(SkinProperty);
```

**XAML 使用方式：**

```xml
<Window x:Class="MyApp.MainWindow"
        xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
        xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
        xmlns:hc="https://handyorg.github.io/handycontrol"
        hc:Theme.Skin="Dark">  <!-- 在这里设置皮肤 -->
    
    <Grid>
        <!-- 内容 -->
    </Grid>
</Window>
```

**代码使用方式：**

```csharp
// 切换整个窗口为暗色主题
Theme.SetSkin(mainWindow, SkinType.Dark);

// 或者只对某个容器设置
Theme.SetSkin(somePanel, SkinType.Dark);
```

### 核心方法：UpdateSkin()

```csharp
protected virtual void UpdateSkin()
{
    // 1. 清除旧的皮肤资源
    MergedDictionaries.Clear();
    
    // 2. 加载新的皮肤资源字典
    var skinDictionary = GetSkin(_skin);
    
    // 3. 如果有自定义强调色，修改皮肤中的颜色
    if (!SyncWithSystem && AccentColor != null)
    {
        UpdateAccentColor(AccentColor.Value);
    }
    
    // 4. 将皮肤资源添加到 MergedDictionaries
    MergedDictionaries.Add(skinDictionary);
    
    // 5. 加载主题资源（包含所有控件样式）
    MergedDictionaries.Add(ResourceHelper.GetTheme());
}

public virtual ResourceDictionary GetSkin(SkinType skinType)
{
    // 使用缓存优化性能
    if (_precSkin == null || _prevSkinType != skinType)
    {
        _precSkin = ResourceHelper.GetSkin(skinType);
        _prevSkinType = skinType;
    }
    
    // 处理强调色
    if (!SyncWithSystem && AccentColor != null)
    {
        UpdateAccentColor(AccentColor.Value);
    }
    
    return _precSkin;
}
```

**性能优化点：**
- 缓存最近使用的皮肤字典（`_precSkin`）
- 只在皮肤类型改变时才重新加载
- 避免频繁创建 ResourceDictionary 对象

```xml
    <Color x:Key="CardBackgroundColor">#FF2D2D2D</Color>    /* 卡片背景 */
    <Color x:Key="RegionColor">#FF262626</Color>             /* 区域背景 */
    
    <!-- 边框颜色调整 */
    <Color x:Key="BorderColor">#FF4C4C4C</Color>            /* 暗色边框 */
    <Color x:Key="LightBorderColor">#FF414141</Color>       /* 浅色边框 */
    
    <!-- 其他颜色可能保持不变或微调 -->
    <Color x:Key="SuccessColor">#FF67C23A</Color>           /* 保持 */
    <Color x:Key="WarningColor">#FFE6A23C</Color>           /* 保持 */
    <Color x:Key="DangerColor">#FFF56C6C</Color>            /* 保持 */

```

**设计原则：**
1. **对比度优先**：确保文本在深色背景下清晰可读
2. **层次分明**：通过不同深度的灰色区分层级
3. **色彩一致**：功能性颜色（成功、警告、错误）通常保持不变
4. **减少眼睛疲劳**：避免使用纯黑 (#000000)，改用深灰

```xml
<ResourceDictionary xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation">

    <!-- 从颜色创建 SolidColorBrush -->
    <SolidColorBrush x:Key="PrimaryBrush" Color="{StaticResource PrimaryColor}"/>

    <SolidColorBrush x:Key="PrimaryDarkBrush" Color="{StaticResource PrimaryDarkColor}"/>
    
    <!-- 语义化画刷 -->
    <SolidColorBrush x:Key="SuccessBrush" Color="{StaticResource SuccessColor}"/>
    <SolidColorBrush x:Key="InfoBrush" Color="{StaticResource InfoColor}"/>
    <SolidColorBrush x:Key="WarningBrush" Color="{StaticResource WarningColor}"/>
    <SolidColorBrush x:Key="DangerBrush" Color="{StaticResource DangerColor}"/>
    
    <!-- 文本画刷 -->
    <SolidColorBrush x:Key="PrimaryTextBrush" Color="{StaticResource PrimaryTextColor}"/>
    <SolidColorBrush x:Key="RegularTextBrush" Color="{StaticResource RegularTextColor}"/>
    <SolidColorBrush x:Key="SecondaryTextBrush" Color="{StaticResource SecondaryTextColor}"/>
    <SolidColorBrush x:Key="PlaceholderBrush" Color="{StaticResource PlaceholderColor}"/>
    
    <!-- 边框画刷 -->
    <SolidColorBrush x:Key="BorderBrush" Color="{StaticResource BorderColor}"/>
    <SolidColorBrush x:Key="LightBorderBrush" Color="{StaticResource LightBorderColor}"/>
    <SolidColorBrush x:Key="DisabledBorderBrush" Color="{StaticResource DisabledBorderColor}"/>
    
    <!-- 背景画刷 -->
    <SolidColorBrush x:Key="BackgroundBrush" Color="{StaticResource PageBackgroundColor}"/>
    <SolidColorBrush x:Key="RegionBrush" Color="{StaticResource RegionColor}"/>
    <SolidColorBrush x:Key="CardBrush" Color="{StaticResource CardBackgroundColor}"/>
    <SolidColorBrush x:Key="MaskBrush" Color="{StaticResource MaskBackgroundColor}"/>
    
    <!-- 特殊画刷 -->
    <SolidColorBrush x:Key="ShadowBrush" Color="{StaticResource ShadowColor}"/>
    
    <!-- 渐变画刷（可选） -->
    <LinearGradientBrush x:Key="PrimaryGradientBrush" StartPoint="0,0" EndPoint="1,1">
        <GradientStop Color="{StaticResource PrimaryLightColor}" Offset="0"/>
        <GradientStop Color="{StaticResource PrimaryColor}" Offset="1"/>
    </LinearGradientBrush>

</ResourceDictionary>
```

**为什么分两层（Color → Brush）？**
1. **灵活性**：可以从同一个 Color 创建不同类型的 Brush（Solid、Linear、Radial）
2. **复用性**：Color 可以用于非 Brush 场景（如透明度计算）
3. **一致性**：确保所有地方使用相同的颜色值

### 关键点解析

#### 1. o:Freeze="True" 冻结对象

```xml
<Geometry o:Freeze="True" x:Key="CalendarGeometry">...</Geometry>
```

**作用：**
- 将 Geometry 对象标记为不可变（Frozen）
- 提升性能：冻结的对象可以跨线程共享
- 减少内存占用：只保存一份副本

**适用对象：**
- Geometry（路径数据）
- Brush（纯色画刷）
- Style（不包含动态绑定的样式）

---

#### 2. 资源加载顺序很重要

WPF 的资源解析遵循**后加载覆盖先加载**的原则：

```
1. Skin*.xaml（颜色）          ← 最先加载，定义原始颜色
2. Basic/Brushes.xaml         ← 基于颜色创建画刷
3. Base/BaseStyle.xaml        ← 基础样式（使用画刷）
4. Styles/*.xaml             ← 控件样式（基于基础样式）
```

这确保了：
- 后面的资源可以引用前面的资源
- 控件样式可以使用已定义的画刷和颜色
- 自定义样式可以覆盖默认样式

## 🔄 动态资源 vs 静态资源

### StaticResource vs DynamicResource

在 HandyControl 的样式中，你会看到两种资源引用方式：

```xml
<Style TargetType="Button">
    <Setter Property="Background" Value="{StaticResource PrimaryBrush}"/>      <!-- 静态 -->
    <Setter Property="Foreground" Value="{DynamicResource PrimaryTextBrush}"/> <!-- 动态 -->
</Style>
```

#### StaticResource（静态资源）

**特点：**
- 在 XAML 加载时**一次性解析**
- 解析后不再改变
- 性能更好（只在启动时查找一次）

**适用场景：**
- 不会改变的资源（如图标 Geometry）
- 启动后就确定的样式
- 性能敏感的场景

**示例：**
```xml
<Path Data="{StaticResource SearchGeometry}" Fill="{StaticResource PrimaryBrush}"/>
```

---

#### DynamicResource（动态资源）

**特点：**
- 在运行时**每次访问都重新解析**
- 当资源发生变化时**自动更新**
- 支持运行时切换主题

**适用场景：**
- 可能会在运行时改变的资源（如主题颜色）
- 需要响应主题切换的场景
- 用户可自定义的资源

**示例：**
```xml
<TextBlock Text="Hello" Foreground="{DynamicResource PrimaryTextBrush}"/>
<!-- 当主题从亮色切换到暗色时，文字颜色会自动更新 -->
```

---

#### HandyControl 的选择策略

| 资源类型 | 使用方式 | 原因 |
|---------|---------|------|
| 颜色 (Color) | StaticResource | 通过 Brush 间接使用 |
| 画刷 (Brush) | DynamicResource | 主题切换时需要更新 |
| 几何图形 (Geometry) | StaticResource | 不会改变 |
| 字体大小 | StaticResource | 通常固定 |
| 样式 (Style) | StaticResource | 通过 BasedOn 继承 |
| 转换器 | StaticResource | 实例不会改变 |

**关键洞察：**
HandyControl 的主题切换之所以有效，是因为控件样式中的 **Brush 引用使用了 DynamicResource**。当皮肤切换时，Brush 资源更新，所有引用它的控件自动刷新。

## 🎨 控件样式体系

### 样式分层架构

HandyControl 采用**三层样式架构**：

```
Level 1: BaseStyle（基础样式）
    ↓ 定义通用的属性（字体、内边距、圆角等）
    
Level 2: ControlBaseStyle（控件基础样式）
    ↓ 定义控件特有的通用属性
    
Level 3: ControlStyle（控件完整样式）
    ↓ 定义完整的 Template 和触发器
```

#### 示例：Button 的样式层次

**1. [BaseStyle.xaml](../src/Shared/HandyControl_Shared/Themes/Styles/Base/BaseStyle.xaml)**

```xml
<Style x:Key="BaseStyle" TargetType="FrameworkElement">
    <!-- 所有控件的通用基础样式 -->
    <Setter Property="SnapsToDevicePixels" Value="True"/>
    <Setter Property="UseLayoutRounding" Value="True"/>
</Style>
```

**2. [ButtonBaseStyle.xaml](../src/Shared/HandyControl_Shared/Themes/Styles/Base/ButtonBaseStyle.xaml)**

```xml
<Style x:Key="ButtonBaseStyle" TargetType="ButtonBase" BasedOn="{StaticResource BaseStyle}">
    <!-- Button 基类的通用样式 -->
    <Setter Property="MinHeight" Value="28"/>
    <Setter Property="Padding" Value="10,0"/>
    <Setter Property="FontSize" Value="{StaticResource TextFontSize}"/>
    <Setter Property="Cursor" Value="Hand"/>
</Style>
```

**3. [Button.xaml](../src/Shared/HandyControl_Shared/Themes/Styles/Button.xaml)**

```xml
<Style TargetType="hc:Button" BasedOn="{StaticResource ButtonBaseStyle}">
    <!-- HandyControl Button 的完整样式 -->
    <Setter Property="Template">
        <Setter.Value>
            <ControlTemplate TargetType="hc:Button">
                <Border x:Name="PART_Border"
                        Background="{TemplateBinding Background}"
                        BorderBrush="{TemplateBinding BorderBrush}"
                        BorderThickness="{TemplateBinding BorderThickness}"
                        CornerRadius="{TemplateBinding hc:BorderElement.CornerRadius}">
                    <ContentPresenter HorizontalAlignment="Center"
                                      VerticalAlignment="Center"/>
                </Border>
                
                <ControlTemplate.Triggers>
                    <Trigger Property="IsMouseOver" Value="True">
                        <Setter TargetName="PART_Border" 
                                Property="Background" 
                                Value="{DynamicResource PrimaryBrush}"/>
                    </Trigger>
                    
                    <Trigger Property="IsPressed" Value="True">
                        <Setter TargetName="PART_Border" 
                                Property="Background" 
                                Value="{DynamicResource PrimaryDarkBrush}"/>
                    </Trigger>
                </ControlTemplate.Triggers>
            </ControlTemplate>
        </Setter.Value>
    </Setter>
</Style>
```

**BasedOn 继承链的优势：**
1. **减少重复**：公共属性只定义一次
2. **易于维护**：修改基础样式会影响所有派生样式
3. **一致性**：确保所有控件有统一的基础外观
4. **可覆盖**：可以在任意级别覆盖特定属性

---

### 样式键命名规范

| 样式类型 | 命名格式 | 示例 |
|---------|---------|------|
| 基础样式 | `{ControlName}BaseStyle` | `TextBoxBaseStyle`, `ButtonBaseStyle` |
| 默认样式 | （无 Key，TargetType 匹配） | `<Style TargetType="hc:Button">` |
| 变体样式 | `{ControlName}{Variant}` | `ButtonPrimary`, `ButtonSuccess` |
| 特殊用途 | 描述性名称 | `WindowWin10Style`, `DialogContainerStyle` |

```csharp
public class ThemeService
{
    public static void ChangeAccentColor(Color color)
    {
        // 方法一：使用 Theme.AccentColor 属性
        if (Application.Current.Resources.MergedDictionaries[0] is Theme theme)
        {
            theme.AccentColor = color;
        }
    }
    
    public static void ToggleDarkMode()
    {
        // 切换暗色模式
        if (Application.Current.Resources.MergedDictionaries[0] is Theme theme)
        {
            theme.Skin = theme.Skin == SkinType.Dark 
                ? SkinType.Default 
                : SkinType.Dark;
        }
    }
    
    public static void EnableSystemSync()
    {
        // 跟随系统主题
        if (Application.Current.Resources.MergedDictionaries[0] is Theme theme)
        {
            theme.SyncWithSystem = true;
        }
    }
}
```

## ⚡ 性能优化技巧

### 1. 冻结免费对象（Freezable）

```csharp
// ❌ 不好的做法：每次都创建新的 Brush
public static Brush GetBackground()
{
    return new SolidColorBrush(Colors.Blue);  // 每次调用都新建
}

// ✅ 好的做法：使用静态资源或冻结对象
private static readonly FrozenBrush = new SolidColorBrush(Colors.Blue);
static MyClass()
{
    FrozenBrush.Freeze();  // 冻结，提升性能
}

public static Brush GetBackground() => FrozenBrush;
```

### 2. 合理使用 StaticResource 和 DynamicResource

```xml
<!-- ✅ 对于不会改变的资源使用 StaticResource -->
<Path Data="{StaticResource SearchGeometry}"/>

<!-- ✅ 对于需要响应主题变化的资源使用 DynamicResource -->
<Border Background="{DynamicResource PrimaryBrush}"/>
```

### 3. 避免过深的资源字典嵌套

```xml
<!-- ❌ 不好的做法：嵌套太深 -->
<ResourceDictionary>
    <ResourceDictionary.MergedDictionaries>
        <ResourceDictionary>
            <ResourceDictionary.MergedDictionaries>
                <!-- 太多层级影响查找性能 -->
            </ResourceDictionary.MergedDictionaries>
        </ResourceDictionary>
    </ResourceDictionary.MergedDictionaries>
</ResourceDictionary>

<!-- ✅ 好的做法：扁平化结构 -->
<ResourceDictionary>
    <ResourceDictionary.MergedDictionaries>
        <ResourceDictionary Source="Colors.xaml"/>
        <ResourceDictionary Source="Brushes.xaml"/>
        <ResourceDictionary Source="Fonts.xaml"/>
    </ResourceDictionary.MergedDictionaries>
</ResourceDictionary>
```

### 4. 使用资源键常量

```csharp
// 使用 ResourceToken 类集中管理
public static class ResourceToken
{
    public const string PrimaryBrush = "PrimaryBrush";
    public const string DangerBrush = "DangerBrush";
    // ...
}

// 使用时
var brush = ResourceHelper.GetResource<Brush>(ResourceToken.PrimaryBrush);
```

## 🔍 调试主题问题

### 常见问题及解决方案

#### 问题 1：主题切换后某些控件没有更新

**原因：** 控件使用了 StaticResource 而不是 DynamicResource

**解决方案：**
检查控件的 Style，将需要响应主题变化的属性改为 DynamicResource：

```xml
<!-- 修改前 -->
<Setter Property="Background" Value="{StaticResource PrimaryBrush}"/>

<!-- 修改后 -->
<Setter Property="Background" Value="{DynamicResource PrimaryBrush}"/>
```

---

#### 问题 2：自定义样式被默认样式覆盖

**原因：** 资源加载顺序问题

**解决方案：**
确保自定义样式在 HandyControl 主题之后加载：

```xml
<ResourceDictionary.MergedDictionaries>
    <!-- 1. 先加载 HandyControl -->
    <ResourceDictionary Source="pack://application:,,,/HandyControl;component/Themes/Theme.xaml"/>
    
    <!-- 2. 再加载自定义样式（会覆盖同名的） -->
    <ResourceDictionary Source="MyCustomStyles.xaml"/>
</ResourceDictionary.MergedDictionaries>
```

---

#### 问题 3：找不到资源

**错误信息：**
```
System.Windows.ResourceReferenceKeyNotFoundException: 
Cannot find resource named 'PrimaryBrush'.
```

**解决方案：**
1. 检查拼写是否正确
2. 确认资源已在正确的位置定义
3. 确认资源字典已被合并
4. 检查是否在资源定义之前就使用了它

**调试方法：**

```csharp
// 在代码中检查资源是否存在
var resource = Application.Current.TryFindResource("PrimaryBrush");
if (resource == null)
{
    Debug.WriteLine("Resource 'PrimaryBrush' not found!");
    // 打印所有已注册的资源键
    PrintAllResourceKeys(Application.Current.Resources);
}

void PrintAllResourceKeys(ResourceDictionary dict)
{
    foreach (var key in dict.Keys)
    {
        Debug.WriteLine($"Resource: {key}");
    }
    foreach (var merged in dict.MergedDictionaries)
    {
        PrintAllResourceKeys(merged);
    }
}
```

## 🎯 最佳实践总结

### ✅ 推荐做法

1. **始终使用 DynamicResource 引用主题相关的 Brush**
2. **通过 ResourceToken 管理资源键名**
3. **创建自定义主题时，只覆盖需要修改的部分**
4. **利用 Theme 类的 AccentColor 属性快速自定义强调色**
5. **测试亮色/暗色两种模式下的效果**
6. **考虑高对比度模式和辅助功能**

### ❌ 避免的做法

1. **硬编码颜色值**（如 `Background="Red"`）
2. **在代码中直接创建 Brush**（应使用资源）
3. **忽略设计器的兼容性**
4. **创建过于复杂的自定义主题**（难以维护）
5. **忘记测试不同 DPI 下的显示效果**
