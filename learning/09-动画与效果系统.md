# HandyControl 深度学习 - 动画与效果系统

## 🎬 媒体层总览

HandyControl 的媒体层位于 [Media/](../src/Shared/HandyControl_Shared/Media/)，提供了 WPF 原生不支持的几何动画和像素着色器效果，让控件拥有更丰富的视觉表现。

### 媒体层结构

```
Media/
├── Animation/                          # 自定义动画
│   ├── GeometryAnimation.cs            # 几何图形动画（核心）
│   ├── GeometryAnimationBase.cs        # 几何动画基类
│   ├── GeometryAnimationUsingKeyFrames.cs  # 关键帧几何动画
│   ├── GeometryKeyFrame.cs             # 关键帧基类
│   ├── GeometryKeyFrameCollection.cs   # 关键帧集合
│   ├── DiscreteGeometryKeyFrame.cs     # 离散关键帧
│   ├── LinearGeometryKeyFrame.cs       # 线性关键帧
│   ├── EasingGeometryKeyFrame.cs       # 缓动关键帧
│   ├── SplineGeometryKeyFrame.cs       # 样条关键帧
│   └── ResolvedKeyFrameEntry.cs        # 解析后的关键帧条目
│
└── Effects/                            # 像素着色器效果
    ├── EffectBase.cs                   # 效果基类
    ├── BrightnessEffect.cs             # 亮度效果
    ├── ContrastEffect.cs               # 对比度效果
    ├── GrayScaleEffect.cs              # 灰度效果
    ├── ColorComplementEffect.cs        # 补色效果
    └── ColorMatrixEffect.cs            # 颜色矩阵效果
```

## 📐 GeometryAnimation 几何动画

WPF 原生动画不支持 `Geometry` 类型的插值动画，HandyControl 通过 [GeometryAnimation.cs](../src/Shared/HandyControl_Shared/Media/Animation/GeometryAnimation.cs) 填补了这个空白。

### 核心特性

- 支持 `PathGeometry` 之间的平滑过渡
- 自动解析路径中的数字序列并插值
- 支持 From/To/By 三种模式
- 支持 EasingFunction 缓动函数

### 类继承关系

```
AnimationTimeline
  └── GeometryAnimationBase
        ├── GeometryAnimation              # From/To 插值
        └── GeometryAnimationUsingKeyFrames  # 关键帧动画
```

### GeometryAnimation 关键代码

```csharp
public class GeometryAnimation : GeometryAnimationBase
{
    // 起始几何图形
    public static readonly DependencyProperty FromProperty = ...;
    public Geometry From { get; set; }

    // 目标几何图形
    public static readonly DependencyProperty ToProperty = ...;
    public Geometry To { get; set; }

    // 增量
    public static readonly DependencyProperty ByProperty = ...;
    public Geometry By { get; set; }

    // 缓动函数
    public static readonly DependencyProperty EasingFunctionProperty = ...;
    public IEasingFunction EasingFunction { get; set; }

    // 是否累加
    public static readonly DependencyProperty IsCumulativeProperty = ...;
    public bool IsCumulative { get; set; }

    protected override Freezable CreateInstanceCore() => new GeometryAnimation();

    // 核心：计算当前进度的几何图形
    protected override Geometry GetCurrentValueCore(Geometry defaultOriginValue,
        Geometry defaultDestinationValue, AnimationClock animationClock)
    {
        // 1. 解析 From/To 几何图形
        // 2. 提取数字序列
        // 3. 按动画进度和缓动函数插值
        // 4. 重新组合为 Geometry 字符串
        // 5. 转换为 Geometry 返回
    }
}
```

### 插值原理

Geometry（尤其是 PathGeometry）本质是一组数字序列。插值的核心思路：

```
原始路径："M 0,0 L 100,0 L 100,100 Z"
数字序列：[0, 0, 100, 0, 100, 100]

目标路径："M 50,50 L 150,50 L 150,150 Z"
数字序列：[50, 50, 150, 50, 150, 150]

进度 0.5 时的插值结果：
数字序列：[25, 25, 125, 25, 125, 125]
路径："M 25,25 L 125,25 L 125,125 Z"
```

### 使用示例

```xml
<Window.Triggers>
    <EventTrigger RoutedEvent="Loaded">
        <BeginStoryboard>
            <Storyboard>
                <hc:GeometryAnimation Storyboard.TargetName="path"
                                      Storyboard.TargetProperty="Data"
                                      From="M 0,0 L 100,0 L 100,100 Z"
                                      To="M 50,50 L 150,50 L 150,150 Z"
                                      Duration="0:0:1"
                                      AutoReverse="True"
                                      RepeatBehavior="Forever">
                    <hc:GeometryAnimation.EasingFunction>
                        <CubicEase EasingMode="EaseInOut"/>
                    </hc:GeometryAnimation.EasingFunction>
                </hc:GeometryAnimation>
            </Storyboard>
        </BeginStoryboard>
    </EventTrigger>
</Window.Triggers>

<Path x:Name="path" Fill="Blue"/>
```

## 🔑 关键帧动画体系

### [GeometryAnimationUsingKeyFrames.cs](../src/Shared/HandyControl_Shared/Media/Animation/GeometryAnimationUsingKeyFrames.cs)

支持关键帧的几何动画，可以定义多个路径关键点。

### 关键帧类型

| 关键帧 | 插值方式 | 用途 |
|--------|---------|------|
| [DiscreteGeometryKeyFrame](../src/Shared/HandyControl_Shared/Media/Animation/DiscreteGeometryKeyFrame.cs) | 无插值（跳变） | 瞬间切换 |
| [LinearGeometryKeyFrame](../src/Shared/HandyControl_Shared/Media/Animation/LinearGeometryKeyFrame.cs) | 线性插值 | 匀速过渡 |
| [EasingGeometryKeyFrame](../src/Shared/HandyControl_Shared/Media/Animation/EasingGeometryKeyFrame.cs) | 缓动函数 | 加减速过渡 |
| [SplineGeometryKeyFrame](../src/Shared/HandyControl_Shared/Media/Animation/SplineGeometryKeyFrame.cs) | 样条曲线 | 自定义曲线 |

### 使用示例

```xml
<hc:GeometryAnimationUsingKeyFrames Storyboard.TargetName="path"
                                     Storyboard.TargetProperty="Data">
    <hc:LinearGeometryKeyFrame KeyTime="0:0:0"
                               Value="M 0,0 L 100,0"/>
    <hc:EasingGeometryKeyFrame KeyTime="0:0:0.5"
                               Value="M 0,0 L 100,100">
        <hc:EasingGeometryKeyFrame.EasingFunction>
            <QuadraticEase EasingMode="EaseIn"/>
        </hc:EasingGeometryKeyFrame.EasingFunction>
    </hc:EasingGeometryKeyFrame>
    <hc:DiscreteGeometryKeyFrame KeyTime="0:0:1"
                                 Value="M 0,0 L 0,100"/>
</hc:GeometryAnimationUsingKeyFrames>
```

## 🎨 ShaderEffect 像素着色器效果

HandyControl 提供了基于 HLSL（High Level Shading Language）的像素着色器效果，位于 [Media/Effects/](../src/Shared/HandyControl_Shared/Media/Effects/)。

### [EffectBase.cs](../src/Shared/HandyControl_Shared/Media/Effects/EffectBase.cs) - 效果基类

所有效果的基类，继承 `ShaderEffect`。

```csharp
public abstract class EffectBase : ShaderEffect
{
    // 输入像素采样器
    public static readonly DependencyProperty InputProperty =
        ShaderEffect.RegisterPixelShaderSamplerProperty("Input", typeof(EffectBase), 0);

    public Brush Input
    {
        get => (Brush)GetValue(InputProperty);
        set => SetValue(InputProperty, value);
    }

    protected EffectBase()
    {
        UpdateShaderValue(InputProperty);
    }
}
```

### 效果列表

| 效果 | 属性 | 说明 |
|------|------|------|
| [BrightnessEffect](../src/Shared/HandyControl_Shared/Media/Effects/BrightnessEffect.cs) | `Brightness` (double) | 亮度调节 |
| [ContrastEffect](../src/Shared/HandyControl_Shared/Media/Effects/ContrastEffect.cs) | `Contrast` (double) | 对比度调节 |
| [GrayScaleEffect](../src/Shared/HandyControl_Shared/Media/Effects/GrayScaleEffect.cs) | `Scale` (double) | 灰度强度 |
| [ColorComplementEffect](../src/Shared/HandyControl_Shared/Media/Effects/ColorComplementEffect.cs) | - | 补色效果 |
| [ColorMatrixEffect](../src/Shared/HandyControl_Shared/Media/Effects/ColorMatrixEffect.cs) | 矩阵参数 | 颜色矩阵变换 |

### BrightnessEffect 示例

```csharp
public class BrightnessEffect : EffectBase
{
    private static readonly PixelShader Shader = new()
    {
        UriSource = new Uri("pack://application:,,,/HandyControl;component/Media/Effects/BrightnessEffect.ps")
    };

    public static readonly DependencyProperty BrightnessProperty =
        DependencyProperty.Register("Brightness", typeof(double), typeof(BrightnessEffect),
            new PropertyMetadata(0.0, PixelShaderConstantCallback(0)));

    public double Brightness
    {
        get => (double)GetValue(BrightnessProperty);
        set => SetValue(BrightnessProperty, value);
    }

    public BrightnessEffect()
    {
        PixelShader = Shader;
        UpdateShaderValue(InputProperty);
        UpdateShaderValue(BrightnessProperty);
    }
}
```

### 使用示例

**XAML 中应用效果：**

```xml
<!-- 灰度效果 -->
<Image Source="photo.jpg">
    <Image.Effect>
        <hc:GrayScaleEffect Scale="0.8"/>
    </Image.Effect>
</Image>

<!-- 亮度效果 -->
<Border Background="Blue">
    <Border.Effect>
        <hc:BrightnessEffect Brightness="0.3"/>
    </Border.Effect>
</Border>

<!-- 对比度效果 -->
<TextBlock Text="Hello" Effect="{hc:ContrastEffect Contrast=1.5}"/>
```

**动画效果：**

```xml
<Image Source="photo.jpg">
    <Image.Style>
        <Style TargetType="Image">
            <Style.Triggers>
                <Trigger Property="IsMouseOver" Value="True">
                    <Trigger.EnterActions>
                        <BeginStoryboard>
                            <Storyboard>
                                <DoubleAnimation Storyboard.TargetProperty="(Image.Effect).(hc:GrayScaleEffect.Scale)"
                                                 From="0" To="1" Duration="0:0:0.3"/>
                            </Storyboard>
                        </BeginStoryboard>
                    </Trigger.EnterActions>
                </Trigger>
            </Style.Triggers>
        </Style>
    </Image.Style>
</Image>
```

### HLSL 着色器原理

以 BrightnessEffect.ps 为例（伪代码）：

```hlsl
sampler2D Input : register(s0);
float Brightness : register(c0);

float4 main(float2 uv : TEXCOORD) : COLOR
{
    float4 color = tex2D(Input, uv);
    color.rgb += Brightness;  // 增加亮度
    return color;
}
```

编译后生成 `.ps` 文件，作为资源嵌入程序集。

## 📊 动画与效果选型指南

| 场景 | 推荐方案 | 原因 |
|------|---------|------|
| 路径变形动画 | `GeometryAnimation` | 原生不支持，HC 提供 |
| 多关键帧路径 | `GeometryAnimationUsingKeyFrames` | 复杂路径动画 |
| 图像灰度/亮度 | `GrayScaleEffect`/`BrightnessEffect` | GPU 加速 |
| 内容切换过渡 | `TransitioningContentControl` | 开箱即用 |
| 数字滚动 | `FloatingBlock` | 内置动画 |
| 文字跑马灯 | `RunningBlock` | 内置动画 |
| 通用属性动画 | WPF 原生 `DoubleAnimation` | 无需自定义 |

## 💡 自定义 ShaderEffect 步骤

### 1. 编写 HLSL 着色器

```hlsl
// MyEffect.ps
sampler2D Input : register(s0);
float MyParameter : register(c0);

float4 main(float2 uv : TEXCOORD) : COLOR
{
    float4 color = tex2D(Input, uv);
    // 自定义处理
    return color;
}
```

### 2. 编译为 .ps 文件

使用 DirectX SDK 的 `fxc.exe` 编译：

```bash
fxc /T ps_2_0 /E main /Fo MyEffect.ps MyEffect.ps
```

### 3. 创建 C# 包装类

```csharp
public class MyEffect : EffectBase
{
    private static readonly PixelShader Shader = new()
    {
        UriSource = new Uri("pack://application:,,,/MyAssembly;component/MyEffect.ps")
    };

    public static readonly DependencyProperty MyParameterProperty =
        DependencyProperty.Register("MyParameter", typeof(double), typeof(MyEffect),
            new PropertyMetadata(0.0, PixelShaderConstantCallback(0)));

    public double MyParameter
    {
        get => (double)GetValue(MyParameterProperty);
        set => SetValue(MyParameterProperty, value);
    }

    public MyEffect()
    {
        PixelShader = Shader;
        UpdateShaderValue(InputProperty);
        UpdateShaderValue(MyParameterProperty);
    }
}
```

### 4. 嵌入资源并使用

将 `.ps` 文件设置为 Resource，在 XAML 中引用。

## ⚡ 性能注意事项

### 1. ShaderEffect 的性能开销

- 像素着色器在 GPU 上执行，性能较好
- 但会增加 GPU 内存占用
- 避免在大量元素上同时使用效果

### 2. GeometryAnimation 的性能

- 每次动画帧都需要重新解析和组合路径字符串
- 避免在复杂路径上使用高频动画
- 简单路径性能可接受

### 3. 冻结动画对象

```csharp
var animation = new DoubleAnimation { From = 0, To = 100, Duration = TimeSpan.FromSeconds(1) };
animation.Freeze();  // 冻结后可跨线程使用，提升性能
```
