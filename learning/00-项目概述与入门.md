# HandyControl 深度学习 - 项目概述与入门

## 📋 项目简介

**HandyControl** 是一个功能强大、设计精美的 WPF UI 控件库，旨在简化 WPF 应用程序的开发过程。该项目提供了大量开箱即用的自定义控件、主题系统和工具类，帮助开发者快速构建现代化的桌面应用程序。

### 核心特性

- ✅ **丰富的控件集**：80+ 自定义控件，覆盖按钮、输入、布局、导航等各类场景
- 🎨 **多主题支持**：内置亮色/暗色主题，支持动态切换
- 🌍 **国际化**：内置多语言支持（中文、英文、日文、韩文等12+语言）
- 🔧 **跨框架兼容**：支持 .NET Framework 4.0/4.5+ 和 Avalonia 跨平台框架
- ⚡ **高性能**：优化的渲染性能和内存管理
- 📱 **现代化UI**：遵循 Material Design 和 Fluent Design 设计理念

### 技术栈

- **核心框架**：WPF (Windows Presentation Foundation)
- **目标平台**：
  - .NET Framework 4.0+
  - .NET Framework 4.5+ (推荐)
  - Avalonia (跨平台)
- **开发语言**：C#
- **构建工具**：MSBuild, Cake
- **包管理**：NuGet, MyGet

## 🚀 快速开始

### 1. 安装

**通过 NuGet 安装（推荐）：**

```bash
# .NET Framework 4.5+
Install-Package HandyControl

# .NET Framework 4.0
Install-Package HandyControl.Net40

# Avalonia 版本
Install-Package HandyControl.Avalonia
```

**或通过 NuGet Package Manager：**

1. 右键项目 → Manage NuGet Packages
2. 搜索 "HandyControl"
3. 选择对应版本并安装

### 2. 基本配置

#### App.xaml 配置

```xml
<Application x:Class="YourApp.App"
             xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
             xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
             StartupUri="MainWindow.xaml">
    <Application.Resources>
        <ResourceDictionary>
            <ResourceDictionary.MergedDictionaries>
                <!-- 引入 HandyControl 主题资源 -->
                <ResourceDictionary Source="pack://application:,,,/HandyControl;component/Themes/Theme.xaml"/>
            </ResourceDictionary.MergedDictionaries>
        </ResourceDictionary>
    </Application.Resources>
</Application>
```

#### 使用示例

**简单按钮示例：**

```xml
<Window x:Class="YourApp.MainWindow"
        xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
        xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
        xmlns:hc="https://handyorg.github.io/handycontrol"
        Title="HandyControl Demo" Height="450" Width="800">
    <StackPanel Margin="10">
        <!-- 使用 HandyControl 按钮 -->
        <hc:Button Content="点击我" 
                   Style="{StaticResource ButtonPrimary}"
                   Click="Button_Click"/>

        <!-- 使用 HandyControl 输入框 -->
        <hc:TextBox hc:InfoElement.Title="用户名"
                    Width="200"
                    Margin="0,10"/>

        <!-- 使用 HandyControl 进度条 -->
        <hc:ProgressBar Value="60" 
                        Width="200"
                        Margin="0,10"/>
    </StackPanel>
</Window>
```

**代码后置：**

```csharp
using System.Windows;
using HandyControl.Controls;

namespace YourApp
{
    public partial class MainWindow : Window
    {
        public MainWindow()
        {
            InitializeComponent();
        }

        private void Button_Click(object sender, RoutedEventArgs e)
        {
            // 显示 Growl 提示
            Growl.Info("Hello, HandyControl!");
            
            // 显示对话框
            Dialog.Show(new TextDialog
            {
                Title = "提示",
                Content = "这是一条消息"
            });
        }
    }
}
```

### 3. 主题切换

```csharp
// 切换到暗色主题
HandyControl.Themes.Theme.SetSkin(this, SkinType.Dark);

// 切换回默认主题
HandyControl.Themes.Theme.SetSkin(this, SkinType.Default);
```

或者在 XAML 中：

```xml
<Window ...
        hc:Theme.Skin="Dark">
    <!-- 窗口内容 -->
</Window>
```

## 📁 解决方案概览

### 主要项目结构

```
HandyControl.sln
├── Shared/                          # 共享代码（核心）
│   ├── HandyControl_Shared/         # 主库源码
│   │   ├── Controls/                # 所有自定义控件
│   │   ├── Data/                    # 数据模型、枚举、配置
│   │   ├── Themes/                  # 主题系统
│   │   ├── Tools/                   # 工具类、辅助方法
│   │   ├── Media/                   # 动画、效果
│   │   └── Interactivity/           # 交互行为
│   ├── HandyControlDemo_Shared/     # Demo 共享代码
│   └── Microsoft.Windows.Shell/     # WindowChrome 支持
├── Net_GE45/                        # .NET 4.5+ 版本
│   └── HandyControl_Net_GE45/
├── Net_40/                          # .NET 4.0 版本
│   └── HandyControl_Net_40/
├── Avalonia/                        # Avalonia 跨平台版本
│   ├── HandyControl_Avalonia/
│   └── HandyControlDemo_Avalonia/
└── build/                           # 构建脚本和配置
```

### 关键目录说明

#### 1. **Controls/** - 控件库核心
包含所有自定义控件的实现，按功能分类：

- `Attach/` - 附加属性和行为
- `Button/` - 按钮相关控件
- `Input/` - 输入控件（TextBox, ComboBox 等）
- `Panel/` - 布局面板
- `Window/` - 窗口控件
- `Dialog/` - 对话框
- 以及更多...

#### 2. **Data/** - 数据层
- `Enum/` - 枚举定义
- `Args/` - 事件参数
- `Info/` - 信息类（MessageBoxInfo, GrowlInfo 等）
- `Range/` - 范围类型
- `Flex/` - Flex 布局相关

#### 3. **Themes/** - 主题系统
- 皮肤资源（SkinDefault.xaml, SkinDark.xaml）
- 主题资源（Theme.xaml）
- 颜色、画刷、样式定义

#### 4. **Tools/** - 工具集
- `Helper/` - 辅助类
- `Converter/` - 值转换器
- `Extension/` - 扩展方法
- `Interop/` - Win32 API 互操作
- `Hook/` - 钩子（键盘、鼠标）

## 💡 核心概念预览

### 1. 依赖属性（DependencyProperty）

HandyControl 大量使用 WPF 的依赖属性系统：

```csharp
public static readonly DependencyProperty TitleProperty = DependencyProperty.Register(
    nameof(Title), typeof(string), typeof(MyControl),
    new PropertyMetadata(default(string)));

public string Title
{
    get => (string)GetValue(TitleProperty);
    set => SetValue(TitleProperty, value);
}
```

### 2. 附加属性（Attached Property）

用于扩展现有控件的功能：

```csharp
public static readonly DependencyProperty IconProperty = DependencyProperty.RegisterAttached(
    "Icon", typeof(string), typeof(IconElement),
    new PropertyMetadata(default(string)));

public static void SetIcon(DependencyObject element, string value)
    => element.SetValue(IconProperty, value);

public static string GetIcon(DependencyObject element)
    => (string)element.GetValue(IconProperty);
```

### 3. 资源字典（ResourceDictionary）

主题和样式的核心载体：

```xml
<ResourceDictionary xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
                    xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml">
    <Style x:Key="ButtonPrimary" TargetType="Button">
        <Setter Property="Background" Value="{DynamicResource PrimaryBrush}"/>
        <Setter Property="Foreground" Value="White"/>
        <!-- 更多样式设置 -->
    </Style>
</ResourceDictionary>
```

### 4. 模板部件（TemplatePart）

自定义控件的标准实现模式：

```csharp
[TemplatePart(Name = "PART_BackElement", Type = typeof(Border))]
public class MyControl : Control
{
    private Border _backElement;
    
    public override void OnApplyTemplate()
    {
        base.OnApplyTemplate();
        _backElement = GetTemplateChild("PART_BackElement") as Border;
        // 初始化模板部件
    }
}
```
