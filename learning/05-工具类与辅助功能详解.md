# HandyControl 深度学习 - 工具类与辅助功能详解

| [Converter/](../src/Shared/HandyControl_Shared/Tools/Converter/) | 32 | IValueConverter 值转换器 |

## 🔧 Helper 辅助类

### [ResourceHelper.cs](../src/Shared/HandyControl_Shared/Tools/Helper/ResourceHelper.cs) - 资源加载

资源访问的统一入口，提供从应用程序资源和 HandyControl 程序集加载资源字典的能力。

```csharp
public class ResourceHelper
{
    // 从 Application.Current 查找资源
    public static T GetResource<T>(string key)
    {
        if (Application.Current.TryFindResource(key) is T resource)
            return resource;
        return default;
    }

    // 从主题字典中查找资源（内部使用）
    internal static T GetResourceInternal<T>(string key);

    // 获取皮肤资源字典（指定程序集）
    public static ResourceDictionary GetSkin(Assembly assembly, string themePath, SkinType skin);

    // 获取 HandyControl 默认皮肤
    public static ResourceDictionary GetSkin(SkinType skin) => new()
    {
        Source = new Uri($"pack://application:,,,/HandyControl;component/Themes/Skin{skin}.xaml")
    };

    // 获取 HandyControl 主题（带缓存）
    private static ResourceDictionary _theme;
    public static ResourceDictionary GetTheme() => _theme ??= GetStandaloneTheme();

    public static ResourceDictionary GetStandaloneTheme() => new()
    {
        Source = new Uri("pack://application:,,,/HandyControl;component/Themes/Theme.xaml")
    };
}
```

**使用场景：**

```csharp
// 获取画刷
var brush = ResourceHelper.GetResource<Brush>(ResourceToken.PrimaryBrush);

// 获取暗色皮肤
var darkSkin = ResourceHelper.GetSkin(SkinType.Dark);
```

**设计要点：**
- `GetTheme()` 使用 `??=` 进行懒加载缓存，避免重复创建 ResourceDictionary
- `GetSkin` 有 try/catch 兜底，找不到指定皮肤时回退到默认皮肤

### [VisualHelper.cs](../src/Shared/HandyControl_Shared/Tools/Helper/VisualHelper.cs) - 视觉树辅助

封装了 WPF 视觉树遍历、命中测试和窗口样式修改等常用操作。

```csharp
public static class VisualHelper
{
    // 递归查找指定类型的子元素
    public static T GetChild<T>(DependencyObject d) where T : DependencyObject;

    // 向上查找指定类型的父元素（遇到 Window 停止）
    public static T GetParent<T>(DependencyObject d) where T : DependencyObject;

    // 获取 Visual 对应的 Win32 句柄
    public static IntPtr GetHandle(this Visual visual);

    // 修改窗口样式（Win32 GWL_STYLE）
    internal static bool ModifyStyle(IntPtr hWnd, int styleToRemove, int styleToAdd);

    // 命中测试（只测试可见且启用的元素）
    internal static void HitTestVisibleElements(Visual visual, HitTestResultCallback callback, HitTestParameters parameters);
}
```

**使用示例：**

```csharp
// 查找窗口中的第一个 AdornerDecorator
var decorator = VisualHelper.GetChild<AdornerDecorator>(window);

// 向上查找父级 Grid
var grid = VisualHelper.GetParent<Grid>(someElement);
```

**实现细节：**
- `GetChild<T>` 使用递归深度优先遍历，找到第一个匹配的元素就返回
- `GetParent<T>` 遇到 `Window` 时返回 null，防止越过窗口边界
- `HitTestVisibleElements` 使用过滤器跳过不可见或禁用的元素

### [ConfigHelper.cs](../src/Shared/HandyControl_Shared/Tools/Helper/ConfigHelper.cs) - 配置管理

单例模式的全局配置管理器，实现 `INotifyPropertyChanged`。

```csharp
public class ConfigHelper : INotifyPropertyChanged
{
    private static readonly Lazy<ConfigHelper> InstanceInternal = new(() => new ConfigHelper(), isThreadSafe: true);
    public static ConfigHelper Instance => InstanceInternal.Value;

    // 当前语言
    public XmlLanguage Lang { get; set; }

    // 设置语言（同时切换线程 UI 文化和 LangProvider）
    public void SetLang(string lang);

    // 应用配置
    public void SetConfig(HandyControlConfig config);

    // 设置动画帧率
    public void SetTimelineFrameRate(int rate);

    // 设置 Window/NavigationWindow 的默认样式
    public void SetWindowDefaultStyle(object resourceKey = null);
    public void SetNavigationWindowDefaultStyle(object resourceKey = null);
}
```

**使用方式：**

```csharp
// 设置语言
ConfigHelper.Instance.SetLang("en");

// 应用完整配置
ConfigHelper.Instance.SetConfig(new HandyControlConfig
{
    Lang = "zh-CN",
    TimelineFrameRate = 60
});
```

**关键设计：**
- 使用 `Lazy<T>` 实现线程安全的单例
- `SetTimelineFrameRate` 通过 `OverrideMetadata` 全局覆盖 `Timeline.DesiredFrameRateProperty` 的默认值

## 🔄 Converter 值转换器

HandyControl 提供了 32 个 `IValueConverter` / `IMultiValueConverter`，覆盖布尔、字符串、颜色、数值、布局等各种转换场景。

### 常用转换器速查

| 转换器 | 输入 → 输出 | 用途 |
|--------|------------|------|
| [Boolean2VisibilityConverter](../src/Shared/HandyControl_Shared/Tools/Converter/) | bool → Visibility | true→Visible，false→Collapsed |
| Boolean2VisibilityReConverter | bool → Visibility | 反向：true→Collapsed |
| BooleanArr2VisibilityConverter | bool[] → Visibility | 多个布尔值的与/或判断 |
| Object2StringConverter | object → string | 对象转字符串 |
| Object2BooleanConverter | object → bool | 非 null → true |
| Object2VisibilityConverter | object → Visibility | 非 null → Visible |
| String2VisibilityConverter | string → Visibility | 非空 → Visible |
| Color2HexStrConverter | Color → string | 颜色转十六进制字符串 |
| Color2ChannelAConverter | Color → double | 提取颜色的 Alpha 通道 |
| Number2PercentageConverter | double → string | 数值转百分比文本 |
| Long2FileSizeConverter | long → string | 字节数转文件大小文本（KB/MB/GB） |
| Double2GridLengthConverter | double → GridLength | 数值转 Grid 长度 |
| Int2StrConverter | int → string | 整数转字符串 |
| BorderClipConverter | Border → Geometry | 计算带圆角的 Border 裁剪几何 |
| BorderCircularClipConverter | Border → Geometry | 圆形裁剪几何 |
| CornerRadiusSplitConverter | CornerRadius → 各边 | 拆分圆角半径 |
| ThicknessSplitConverter | Thickness → 各边 | 拆分边距 |
| TreeViewItemMarginConverter | int → Thickness | TreeView 缩进计算 |

### 使用示例

**XAML 中使用：**

```xml
<!-- 转换器已在 Theme.xaml 中注册为实例资源 -->
<TextBlock Text="{Binding FileSize, Converter={StaticResource Long2FileSizeConverter}}"/>

<Border Visibility="{Binding IsEmpty, Converter={StaticResource Boolean2VisibilityReConverter}}"/>

<!-- 颜色转十六进制 -->
<TextBox Text="{Binding SelectedColor, Converter={StaticResource Color2HexStrConverter}}"/>
```

**Color2HexStrConverter 实现思路：**

```csharp
public class Color2HexStrConverter : IValueConverter
{
    public object Convert(object value, Type targetType, object parameter, CultureInfo culture)
    {
        if (value is Color color)
        {
            return color.A == 255
                ? $"#{color.R:X2}{color.G:X2}{color.B:X2}"
                : $"#{color.A:X2}{color.R:X2}{color.G:X2}{color.B:X2}";
        }
        return string.Empty;
    }
}
```

### 实现原理

所有钩子都基于 Win32 `SetWindowsHookEx`：

```csharp
// 伪代码
private IntPtr _hookId;

public void Start()
{
    _hookId = InteropMethods.SetWindowsHookEx(
        HookType.WH_KEYBOARD_LL,  // 低级别键盘钩子
        HookCallback,
        InteropMethods.GetModuleHandle(null),
        0);
}

private IntPtr HookCallback(int nCode, IntPtr wParam, IntPtr lParam)
{
    // 解析按键信息并触发事件
    var keyInfo = Marshal.PtrToStructure<KBDLLHOOKSTRUCT>(lParam);
    KeyDown?.Invoke(this, new KeyboardHookEventArgs { Key = ... });

    return InteropMethods.CallNextHookEx(_hookId, nCode, wParam, lParam);
}
```

## 🎯 工具层设计模式总结

### 1. 静态类模式

Helper 类大多为 `static`，无需实例化，直接调用：

```csharp
// 直接调用静态方法
var brush = ResourceHelper.GetResource<Brush>("PrimaryBrush");
var parent = VisualHelper.GetParent<Grid>(element);
```

### 2. 单例模式

`ConfigHelper` 使用 `Lazy<T>` 实现线程安全单例：

```csharp
private static readonly Lazy<ConfigHelper> InstanceInternal = new(() => new ConfigHelper(), isThreadSafe: true);
public static ConfigHelper Instance => InstanceInternal.Value;
```

### 3. P/Invoke 集中管理

所有 Win32 声明集中在 `InteropMethods`，常量集中在 `InteropValues`，避免散落。

### 4. SafeHandle 模式

使用 `SafeHandle` 派生类管理非托管句柄，确保 GC 正确回收。

### 5. 扩展方法模式

通过 `this` 关键字为现有类型添加方法，保持 API 流畅：

```csharp
// 扩展方法调用
var isValid = email.IsEmail();
var color = 0xFFFF0000.ToColor();
```

## 💡 最佳实践

### 1. 优先使用 Helper 而非自己实现

```csharp
// ❌ 不好的做法：自己写遍历
T FindChild<T>(DependencyObject parent)
{
    // 手动遍历视觉树...
}

// ✅ 好的做法：使用 VisualHelper
var child = VisualHelper.GetChild<T>(parent);
```

### 2. 使用 ResourceHelper 统一资源访问

```csharp
// ❌ 硬编码字符串
var brush = (Brush)Application.Current.FindResource("PrimaryBrush");

// ✅ 使用 ResourceHelper + ResourceToken
var brush = ResourceHelper.GetResource<Brush>(ResourceToken.PrimaryBrush);
```

### 3. 扩展方法保持无副作用

扩展方法应是纯函数，不修改对象状态，只返回新值。
