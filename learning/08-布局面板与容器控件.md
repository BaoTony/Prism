# HandyControl 深度学习 - 布局面板与容器控件

## 📐 布局面板总览

HandyControl 提供了多种强大的自定义布局面板，弥补 WPF 原生布局的不足，实现了类似 CSS Flexbox、瀑布流、圆形排列、蜂窝网格、相对布局等现代布局能力。

### 面板一览

| 面板 | 基类 | 布局方式 | 典型场景 |
|------|------|---------|---------|
| [FlexPanel](../src/Shared/HandyControl_Shared/Controls/Panel/FlexPanel.cs) | `Panel` | CSS Flexbox 弹性布局 | 响应式、自适应排列 |
| [WaterfallPanel](../src/Shared/HandyControl_Shared/Controls/Panel/WaterfallPanel.cs) | `Panel` | 瀑布流 | 图片墙、卡片列表 |
| [CirclePanel](../src/Shared/HandyControl_Shared/Controls/Panel/CirclePanel.cs) | `Panel` | 圆形排列 | 仪表盘、菜单 |
| [HoneycombPanel](../src/Shared/HandyControl_Shared/Controls/Panel/HoneycombPanel.cs) | `Panel` | 蜂窝/六边形网格 | 蜂窝状展示 |
| [RelativePanel](../src/Shared/HandyControl_Shared/Controls/Panel/RelativePanel.cs) | `Panel` | 相对定位 | 复杂相对布局 |
| [UniformSpacingPanel](../src/Shared/HandyControl_Shared/Controls/Panel/UniformSpacingPanel.cs) | `Panel` | 均匀间距排列 | 均匀间隔的列表 |
| [SimplePanel](../src/Shared/HandyControl_Shared/Controls/Panel/SimplePanel.cs) | `Panel` | 简单堆叠 | 基础容器 |
| [SimpleStackPanel](../src/Shared/HandyControl_Shared/Controls/Panel/SimpleStackPanel.cs) | `Panel` | 简化栈 | 性能优化的栈 |

## 🌊 [FlexPanel.cs](../src/Shared/HandyControl_Shared/Controls/Panel/FlexPanel.cs) - 弹性布局

实现了 CSS Flexbox 规范的 WPF 面板，是 HandyControl 最强大的布局控件。

### 面板级属性

| 属性 | 类型 | 对应 CSS | 说明 |
|------|------|---------|------|
| `FlexDirection` | `FlexDirection` | `flex-direction` | 主轴方向 |
| `FlexWrap` | `FlexWrap` | `flex-wrap` | 换行方式 |
| `JustifyContent` | `FlexContentJustify` | `justify-content` | 主轴对齐 |
| `AlignItems` | `FlexItemsAlignment` | `align-items` | 交叉轴对齐 |
| `AlignContent` | `FlexContentAlignment` | `align-content` | 多行对齐 |

### 子元素附加属性

| 属性 | 类型 | 对应 CSS | 说明 |
|------|------|---------|------|
| `Order` | `int` | `order` | 排列顺序 |
| `FlexGrow` | `double` | `flex-grow` | 放大比例 |
| `FlexShrink` | `double` | `flex-shrink` | 缩小比例 |
| `FlexBasis` | `double` | `flex-basis` | 初始大小 |
| `AlignSelf` | `FlexItemAlignment` | `align-self` | 单独对齐 |

### FlexDirection 枚举

```csharp
public enum FlexDirection
{
    Row,           // 水平（左→右）
    RowReverse,    // 水平反向（右→左）
    Column,        // 垂直（上→下）
    ColumnReverse  // 垂直反向（下→上）
}
```

### FlexWrap 枚举

```csharp
public enum FlexWrap
{
    NoWrap,       // 不换行
    Wrap,         // 换行
    WrapReverse   // 反向换行
}
```

### 使用示例

**水平均匀分布：**

```xml
<hc:FlexPanel JustifyContent="SpaceBetween">
    <Button Content="左"/>
    <Button Content="中"/>
    <Button Content="右"/>
</hc:FlexPanel>
```

**自适应换行（类似 WrapPanel）：**

```xml
<hc:FlexPanel FlexWrap="Wrap"
              JustifyContent="FlexStart"
              AlignItems="Center"
              Gap="8">
    <Border Width="80" Height="40" Background="Red"/>
    <Border Width="120" Height="40" Background="Green"/>
    <Border Width="60" Height="40" Background="Blue"/>
    <!-- 自动换行 -->
</hc:FlexPanel>
```

**FlexGrow 分配空间：**

```xml
<hc:FlexPanel>
    <!-- 占 1 份 -->
    <Border Background="Red" hc:FlexPanel.FlexGrow="1"/>
    <!-- 占 2 份 -->
    <Border Background="Green" hc:FlexPanel.FlexGrow="2"/>
    <!-- 占 1 份 -->
    <Border Background="Blue" hc:FlexPanel.FlexGrow="1"/>
</hc:FlexPanel>
```

**垂直居中对齐：**

```xml
<hc:FlexPanel JustifyContent="Center"
              AlignItems="Center"
              Height="200">
    <TextBlock Text="垂直水平居中"/>
</hc:FlexPanel>
```

### 实现原理

`MeasureOverride` 负责：
1. 计算主轴方向上每个子元素的尺寸
2. 根据 `FlexGrow`/`FlexShrink` 分配剩余空间
3. 根据 `FlexWrap` 决定是否换行

`ArrangeOverride` 负责：
1. 按行分组
2. 根据 `JustifyContent` 计算每行的起始位置和间距
3. 根据 `AlignItems`/`AlignContent` 计算交叉轴位置
4. 调用 `Arrange` 排列每个子元素

## 🏞️ [WaterfallPanel.cs](../src/Shared/HandyControl_Shared/Controls/Panel/WaterfallPanel.cs) - 瀑布流

实现类似 Pinterest 的瀑布流布局。

### 关键属性

| 属性 | 类型 | 说明 |
|------|------|------|
| `ItemWidth` | `double` | 每个子项的固定宽度 |
| `Columns` | `int` | 列数（0 表示自动计算） |

### 使用示例

```xml
<hc:WaterfallPanel ItemWidth="150">
    <Border Height="100" Background="Red" Margin="4"/>
    <Border Height="150" Background="Green" Margin="4"/>
    <Border Height="80" Background="Blue" Margin="4"/>
    <Border Height="120" Background="Yellow" Margin="4"/>
    <Border Height="200" Background="Purple" Margin="4"/>
</hc:WaterfallPanel>
```

### 布局算法

1. 根据 `ItemWidth` 和面板宽度计算列数
2. 维护每列的当前高度
3. 每个新元素放入当前最矮的列
4. 形成错落有致的瀑布效果

## ⭕ [CirclePanel.cs](../src/Shared/HandyControl_Shared/Controls/Panel/CirclePanel.cs) - 圆形布局

将子元素沿圆周排列。

### 关键属性

| 属性 | 类型 | 说明 |
|------|------|------|
| `Diameter` | `double` | 圆的直径 |
| `KeepVertical` | `bool` | 子元素是否保持垂直（不旋转） |
| `OffsetAngle` | `double` | 起始角度偏移 |

### 使用示例

```xml
<hc:CirclePanel Diameter="300"
                KeepVertical="True"
                OffsetAngle="-90">
    <Button Content="1" Width="40" Height="40"/>
    <Button Content="2" Width="40" Height="40"/>
    <Button Content="3" Width="40" Height="40"/>
    <Button Content="4" Width="40" Height="40"/>
    <Button Content="5" Width="40" Height="40"/>
    <Button Content="6" Width="40" Height="40"/>
</hc:CirclePanel>
```

### 布局算法

```csharp
protected override Size ArrangeOverride(Size finalSize)
{
    var centerX = finalSize.Width / 2;
    var centerY = finalSize.Height / 2;
    var radius = Diameter / 2;
    var count = InternalChildren.Count;

    for (int i = 0; i < count; i++)
    {
        // 计算每个元素的角度
        var angle = (360.0 / count) * i + OffsetAngle;
        var radian = angle * Math.PI / 180;

        // 计算位置
        var x = centerX + radius * Math.Cos(radian);
        var y = centerY + radius * Math.Sin(radian);

        var child = InternalChildren[i];
        child.Arrange(new Rect(x - child.DesiredSize.Width / 2,
                               y - child.DesiredSize.Height / 2,
                               child.DesiredSize.Width,
                               child.DesiredSize.Height));
    }

    return finalSize;
}
```

## 🎯 [RelativePanel.cs](../src/Shared/HandyControl_Shared/Controls/Panel/RelativePanel.cs) - 相对布局

通过子元素之间的相对关系进行布局，类似 UWP 的 RelativePanel。

### 附加属性

**与面板边缘对齐：**
- `AlignLeftWithPanel`
- `AlignRightWithPanel`
- `AlignTopWithPanel`
- `AlignBottomWithPanel`
- `AlignHorizontalCenterWithPanel`
- `AlignVerticalCenterWithPanel`

**与其他元素对齐：**
- `LeftOf`
- `RightOf`
- `Above`
- `Below`
- `AlignLeftWith`
- `AlignRightWith`
- `AlignTopWith`
- `AlignBottomWith`
- `AlignHorizontalCenterWith`
- `AlignVerticalCenterWith`

### 使用示例

```xml
<hc:RelativePanel>
    <Button x:Name="okBtn" Content="确定" Width="80"
            hc:RelativePanel.AlignRightWithPanel="True"
            hc:RelativePanel.AlignBottomWithPanel="True"/>

    <Button x:Name="cancelBtn" Content="取消" Width="80"
            hc:RelativePanel.LeftOf="okBtn"
            hc:RelativePanel.AlignBottomWith="okBtn"
            Margin="0,0,8,0"/>

    <TextBox x:Name="input" Width="200"
             hc:RelativePanel.Above="okBtn"
             hc:RelativePanel.AlignLeftWithPanel="True"
             Margin="0,0,0,12"/>
</hc:RelativePanel>
```

### 实现原理 - 依赖图

RelativePanel 内部构建了一个依赖图来解决布局：

```csharp
// 简化的依赖图节点
internal class GraphNode
{
    public UIElement Element { get; set; }
    public List<GraphNode> Dependencies { get; } = new();
    public double Left, Top, Right, Bottom;
}

// MeasureOverride 中：
// 1. 为每个子元素创建节点
// 2. 根据附加属性建立依赖关系
// 3. 检测循环依赖（抛出异常）
// 4. 按拓扑序计算每个节点的位置
```

## 💡 自定义 Panel 开发指南

### 基本结构

```csharp
public class MyPanel : Panel
{
    // 测量：计算面板需要的尺寸
    protected override Size MeasureOverride(Size availableSize)
    {
        var desiredSize = new Size();

        foreach (UIElement child in InternalChildren)
        {
            // 让子元素测量自己
            child.Measure(availableSize);

            // 累加尺寸（根据布局策略）
            desiredSize.Width += child.DesiredSize.Width;
            desiredSize.Height = Math.Max(desiredSize.Height, child.DesiredSize.Height);
        }

        return desiredSize;
    }

    // 排列：确定每个子元素的位置
    protected override Size ArrangeOverride(Size finalSize)
    {
        double x = 0;

        foreach (UIElement child in InternalChildren)
        {
            child.Arrange(new Rect(x, 0, child.DesiredSize.Width, child.DesiredSize.Height));
            x += child.DesiredSize.Width;
        }

        return finalSize;
    }
}
```

### 关键方法说明

| 方法 | 职责 |
|------|------|
| `MeasureOverride` | 计算面板期望大小，递归调用子元素 `Measure` |
| `ArrangeOverride` | 确定每个子元素的最终位置和大小 |

### 注意事项

1. **`Measure` 必须调用**：每个子元素必须调用 `Measure`，否则 `DesiredSize` 为 0
2. **availableSize 可能为 Infinity**：需要处理 Infinity 的情况
3. **性能**：避免在 ArrangeOverride 中分配大量临时对象
4. **附加属性**：通过 `RegisterAttached` 为子元素提供布局参数
