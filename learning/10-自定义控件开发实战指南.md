# HandyControl 深度学习 - 自定义控件开发实战指南

## 🎯 开发流程总览

开发一个符合 HandyControl 规范的自定义控件，需要遵循从需求到发布的完整流程。本章以实战角度总结 HandyControl 源码中体现的开发模式和最佳实践。

### 开发流程

```
1. 需求分析
   ↓
2. 确定继承基类
   ↓
3. 定义依赖属性和事件
   ↓
4. 声明 TemplatePart
   ↓
5. 实现控件逻辑
   ↓
6. 编写默认样式和模板
   ↓
7. 注册到 Theme.xaml
   ↓
8. 编写 XML 文档注释
   ↓
9. 编写 Demo 示例
   ↓
10. 测试与优化
```

---

## 📋 第一步：需求分析

在动手写代码前，明确以下问题：

| 问题 | 示例回答 |
|------|---------|
| 控件解决什么问题？ | 提供验证码输入能力 |
| 继承哪个基类？ | `Control`（需要完全自定义视觉） |
| 需要哪些依赖属性？ | `Password`, `Length`, `Completed` 事件 |
| 需要哪些 TemplatePart？ | `PART_Panel`（承载输入格子） |
| 是否需要命令支持？ | 否 |
| 是否需要主题支持？ | 是，使用 DynamicResource |

## 🏗️ 第二步：确定继承基类

### 基类选型决策树

```
是否需要自定义标题栏/非客户区？
├─ 是 → 继承 hc:Window
└─ 否 ↓
   是否是弹出窗口？
   ├─ 是 → 继承 PopupWindow
   └─ 否 ↓
      是否需要 ItemsControl 功能？
      ├─ 是 → 继承 SimpleItemsControl / RegularItemsControl
      └─ 否 ↓
         是否需要 ContentControl 功能（单一内容）？
         ├─ 是 → 继承 ContentControl
         └─ 否 ↓
            是否需要可选择状态？
            ├─ 是 → 继承 SelectableItem
            └─ 否 ↓
               是否需要完全自定义视觉树？
               ├─ 是 → 继承 Control
               └─ 否 → 继承合适的原生控件
```

### 常见基类对比

| 基类 | 适用场景 | 优点 | 缺点 |
|------|---------|------|------|
| `Control` | 全新视觉控件 | 最灵活 | 需要完整实现模板 |
| `ContentControl` | 单一内容容器 | 内置 Content 支持 | 模板需包含 ContentPresenter |
| `ItemsControl` | 集合控件 | 内置 Items 支持 | 需处理容器生成 |
| `SelectableItem` | 可选择项 | 内置 IsSelected | 需配合 ItemsControl |
| 原生控件 | 少量扩展 | 继承现有功能 | 受限于原生模板 |

## 🔧 第三步：定义依赖属性

### 命名规范

```csharp
// 属性名 + Property 后缀
public static readonly DependencyProperty ValueProperty =
    DependencyProperty.Register(nameof(Value), ...);

public double Value
{
    get => (double)GetValue(ValueProperty);
    set => SetValue(ValueProperty, value);
}
```

### 使用 ValueBoxes 优化

```csharp
// ❌ 不好：每次设置默认值都装箱
new PropertyMetadata(false);

// ✅ 好：使用预装箱值
new PropertyMetadata(ValueBoxes.FalseBox);
```

### 属性元数据选项

```csharp
public static readonly DependencyProperty ValueProperty = DependencyProperty.Register(
    nameof(Value),
    typeof(double),
    typeof(MyControl),
    new FrameworkPropertyMetadata(
        0.0,                                    // 默认值
        FrameworkPropertyMetadataOptions.BindsTwoWayByDefault,  // 双向绑定
        OnValueChanged,                         // 变更回调
        OnCoerceValue));                        // 强制值回调
```

### 依赖属性变更回调模式

```csharp
private static void OnValueChanged(DependencyObject d, DependencyPropertyChangedEventArgs e)
{
    if (d is MyControl control)
    {
        control.UpdateVisualState();
        control.RaiseValueChanged((double)e.NewValue);
    }
}
```

### 强制值回调（CoerceValueCallback）

```csharp
private static object OnCoerceValue(DependencyObject d, object baseValue)
{
    var value = (double)baseValue;
    var control = (MyControl)d;
    // 限制在有效范围内
    return Math.Clamp(value, control.Minimum, control.Maximum);
}
```

## 🎨 第四步：声明 TemplatePart

### 声明规范

```csharp
[TemplatePart(Name = PartPanel, Type = typeof(Panel))]
[TemplatePart(Name = PartButton, Type = typeof(ButtonBase))]
public class MyControl : Control
{
    // 命名常量
    private const string PartPanel = "PART_Panel";
    private const string PartButton = "PART_Button";

    // 字段
    private Panel _panel;
    private ButtonBase _button;
}
```

### 命名约定

| 前缀 | 含义 | 示例 |
|------|------|------|
| `PART_` | 必需的模板部件 | `PART_Panel`, `PART_TextBox` |
| `Element` | 内部使用的部件名 | `ElementPanel = "PART_Panel"` |

### 命名规范（HandyControl 风格）

HandyControl 使用 `Element` 前缀定义常量，值为 `PART_` 前缀：

```csharp
private const string ElementPanel = "PART_Panel";
private const string ElementButton = "PART_Button";
```

## ⚙️ 第五步：实现控件逻辑

### 静态构造函数 - 设置 DefaultStyleKey

```csharp
static MyControl()
{
    // 确保使用自定义默认样式
    DefaultStyleKeyProperty.OverrideMetadata(typeof(MyControl),
        new FrameworkPropertyMetadata(typeof(MyControl)));
}
```

### 实例构造函数 - 命令绑定

```csharp
public MyControl()
{
    // 绑定内置命令
    CommandBindings.Add(new CommandBinding(ControlCommands.Clear,
        (s, e) => { /* 清除逻辑 */ }));
}
```

### OnApplyTemplate - 获取模板部件

```csharp
public override void OnApplyTemplate()
{
    // 先清理旧的事件绑定
    if (_button != null)
    {
        _button.Click -= Button_Click;
    }

    base.OnApplyTemplate();

    // 获取新的模板部件
    _panel = GetTemplateChild(ElementPanel) as Panel;
    _button = GetTemplateChild(ElementButton) as ButtonBase;

    // 绑定新事件
    if (_button != null)
    {
        _button.Click += Button_Click;
    }

    // 初始化
    UpdateVisualState();
}
```

### 事件处理

```csharp
private void Button_Click(object sender, RoutedEventArgs e)
{
    // 业务逻辑
    Value++;
}
```

### 重写鼠标/键盘事件

```csharp
protected override void OnMouseLeftButtonDown(MouseButtonEventArgs e)
{
    base.OnMouseLeftButtonDown(e);
    // 处理点击
}

protected override void OnKeyDown(KeyEventArgs e)
{
    base.OnKeyDown(e);
    if (e.Key == Key.Enter)
    {
        // 处理回车
    }
}
```

## 🖼️ 第六步：编写默认样式和模板

### 样式文件结构

在 `Themes/Styles/` 下创建 `MyControl.xaml`：

```xml
<ResourceDictionary xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
                    xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
                    xmlns:hc="https://handyorg.github.io/handycontrol">

    <!-- 基础样式 -->
    <Style x:Key="MyControlBaseStyle" TargetType="hc:MyControl">
        <Setter Property="Template">
            <Setter.Value>
                <ControlTemplate TargetType="hc:MyControl">
                    <Border Background="{TemplateBinding Background}"
                            BorderBrush="{TemplateBinding BorderBrush}"
                            BorderThickness="{TemplateBinding BorderThickness}"
                            CornerRadius="{TemplateBinding hc:BorderElement.CornerRadius}">
                        <Grid>
                            <Grid.RowDefinitions>
                                <RowDefinition Height="Auto"/>
                                <RowDefinition Height="*"/>
                            </Grid.RowDefinitions>

                            <!-- 标题 -->
                            <ContentPresenter Grid.Row="0"
                                              Content="{TemplateBinding Header}"/>

                            <!-- 内容区 -->
                            <Panel x:Name="PART_Panel" Grid.Row="1"/>
                        </Grid>
                    </Border>

                    <ControlTemplate.Triggers>
                        <Trigger Property="IsEnabled" Value="False">
                            <Setter Property="Opacity" Value="0.5"/>
                        </Trigger>
                    </ControlTemplate.Triggers>
                </ControlTemplate>
            </Setter.Value>
        </Setter>
    </Style>

    <!-- 默认样式（无 Key，自动应用） -->
    <Style TargetType="hc:MyControl" BasedOn="{StaticResource MyControlBaseStyle}"/>

</ResourceDictionary>
```

### TemplateBinding vs Binding

| 用法 | 场景 |
|------|------|
| `{TemplateBinding Background}` | 模板内绑定控件自身属性，性能好 |
| `{Binding Background, RelativeSource={RelativeSource TemplatedParent}}` | 需要复杂转换时 |

### 主题资源引用

```xml
<!-- ✅ 使用 DynamicResource 引用主题画刷 -->
<Border Background="{DynamicResource RegionBrush}"/>

<!-- ✅ 使用 StaticResource 引用不变的资源 -->
<Geometry Data="{StaticResource SearchGeometry}"/>

<!-- ❌ 硬编码颜色 -->
<Border Background="#FF3C8DBC"/>
```

## 🎯 完整实战：开发一个 Rating 评分控件

### 1. 控件类

```csharp
using System.Windows;
using System.Windows.Controls;
using System.Windows.Input;
using HandyControl.Data;

namespace HandyControl.Controls;

[TemplatePart(Name = ElementPanel, Type = typeof(Panel))]
public class Rating : Control
{
    private const string ElementPanel = "PART_Panel";

    private Panel _panel;

    #region Value

    public static readonly DependencyProperty ValueProperty = DependencyProperty.Register(
        nameof(Value), typeof(double), typeof(Rating),
        new FrameworkPropertyMetadata(ValueBoxes.Double0Box,
            FrameworkPropertyMetadataOptions.BindsTwoWayByDefault, OnValueChanged));

    public double Value
    {
        get => (double)GetValue(ValueProperty);
        set => SetValue(ValueProperty, value);
    }

    private static void OnValueChanged(DependencyObject d, DependencyPropertyChangedEventArgs e)
    {
        if (d is Rating rating) rating.UpdateVisualState();
    }

    #endregion

    #region MaxValue

    public static readonly DependencyProperty MaxValueProperty = DependencyProperty.Register(
        nameof(MaxValue), typeof(int), typeof(Rating),
        new PropertyMetadata(ValueBoxes.Int5Box, OnMaxValueChanged));

    public int MaxValue
    {
        get => (int)GetValue(MaxValueProperty);
        set => SetValue(MaxValueProperty, value);
    }

    private static void OnMaxValueChanged(DependencyObject d, DependencyPropertyChangedEventArgs e)
    {
        if (d is Rating rating) rating.GenerateItems();
    }

    #endregion

    #region ValueChanged 事件

    public static readonly RoutedEvent ValueChangedEvent = EventManager.RegisterRoutedEvent(
        "ValueChanged", RoutingStrategy.Bubble,
        typeof(EventHandler<FunctionEventArgs<double>>), typeof(Rating));

    public event EventHandler<FunctionEventArgs<double>> ValueChanged
    {
        add => AddHandler(ValueChangedEvent, value);
        remove => RemoveHandler(ValueChangedEvent, value);
    }

    #endregion

    static Rating()
    {
        DefaultStyleKeyProperty.OverrideMetadata(typeof(Rating),
            new FrameworkPropertyMetadata(typeof(Rating)));
    }

    public override void OnApplyTemplate()
    {
        base.OnApplyTemplate();
        _panel = GetTemplateChild(ElementPanel) as Panel;
        GenerateItems();
    }

    private void GenerateItems()
    {
        if (_panel == null) return;

        _panel.Children.Clear();
        for (int i = 0; i < MaxValue; i++)
        {
            var item = new RatingItem { Index = i + 1 };
            item.MouseEnter += Item_MouseEnter;
            item.MouseLeave += Item_MouseLeave;
            item.PreviewMouseLeftButtonUp += Item_Click;
            _panel.Children.Add(item);
        }
        UpdateVisualState();
    }

    private int _hoverIndex = -1;

    private void Item_MouseEnter(object sender, MouseEventArgs e)
    {
        if (sender is RatingItem item)
        {
            _hoverIndex = item.Index;
            UpdateVisualState();
        }
    }

    private void Item_MouseLeave(object sender, MouseEventArgs e)
    {
        _hoverIndex = -1;
        UpdateVisualState();
    }

    private void Item_Click(object sender, MouseButtonEventArgs e)
    {
        if (sender is RatingItem item)
        {
            Value = item.Index;
            RaiseEvent(new FunctionEventArgs<double>(Value, ValueChangedEvent));
        }
    }

    private void UpdateVisualState()
    {
        if (_panel == null) return;

        for (int i = 0; i < _panel.Children.Count; i++)
        {
            if (_panel.Children[i] is RatingItem item)
            {
                var threshold = _hoverIndex >= 0 ? _hoverIndex : Value;
                item.IsFilled = (i + 1) <= threshold;
            }
        }
    }
}
```

### 2. RatingItem 子控件

```csharp
public class RatingItem : Control
{
    public static readonly DependencyProperty IndexProperty = DependencyProperty.Register(
        nameof(Index), typeof(int), typeof(RatingItem));

    public int Index
    {
        get => (int)GetValue(IndexProperty);
        set => SetValue(IndexProperty, value);
    }

    public static readonly DependencyProperty IsFilledProperty = DependencyProperty.Register(
        nameof(IsFilled), typeof(bool), typeof(RatingItem),
        new PropertyMetadata(ValueBoxes.FalseBox));

    public bool IsFilled
    {
        get => (bool)GetValue(IsFilledProperty);
        set => SetValue(IsFilledProperty, ValueBoxes.BooleanBox(value));
    }

    static RatingItem()
    {
        DefaultStyleKeyProperty.OverrideMetadata(typeof(RatingItem),
            new FrameworkPropertyMetadata(typeof(RatingItem)));
    }
}
```

## 🔍 代码审查清单

提交控件代码前，请对照以下清单：

### 代码质量

- [ ] 所有公共 API 有 XML 文档注释
- [ ] 依赖属性使用 `nameof()` 而非字符串
- [ ] 依赖属性默认值使用 `ValueBoxes`
- [ ] `OnApplyTemplate` 中先注销旧事件再注册新事件
- [ ] TemplatePart 获取后进行 null 检查
- [ ] 样式使用 `DynamicResource` 引用主题颜色

### 功能完整性

- [ ] 静态构造函数设置了 `DefaultStyleKey`
- [ ] 样式已注册到 `Theme.xaml`
- [ ] 亮色/暗色主题都正常
- [ ] 禁用状态视觉正确

### 性能

- [ ] 不在 `MeasureOverride`/`ArrangeOverride` 中分配对象
- [ ] 事件处理器在卸载时正确注销
- [ ] 合理使用 `Freeze` 冻结 Freezable 对象
