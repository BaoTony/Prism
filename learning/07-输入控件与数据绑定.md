# HandyControl 深度学习 - 输入控件与数据绑定

## ⌨️ 输入控件总览

HandyControl 对 WPF 原生输入控件进行了增强，并新增了多个实用输入控件，覆盖文本、密码、数值、日期时间、选择、搜索等常见场景。

### 输入控件分类

| 分类 | 控件 | 基类 | 说明 |
|------|------|------|------|
| **文本** | [TextBox](../src/Shared/HandyControl_Shared/Controls/Input/TextBox.cs) | `System.Windows.Controls.TextBox` | 增强文本框（清除按钮） |

| **密码** | [PasswordBox](../src/Shared/HandyControl_Shared/Controls/Input/PasswordBox.cs) | `Control` | 密码框（可切换明文） |
| | [PinBox](../src/Shared/HandyControl_Shared/Controls/Input/PinBox.cs) | `Control` | PIN 码/验证码输入 |

| **选择** | [ComboBox](../src/Shared/HandyControl_Shared/Controls/Input/ComboBox.cs) | `System.Windows.Controls.ComboBox` | 增强下拉框（自动完成） |
| | [CheckComboBox](../src/Shared/HandyControl_Shared/Controls/Input/CheckComboBox/) | `ListBox` | 多选下拉框 |

## 📝 [TextBox.cs](../src/Shared/HandyControl_Shared/Controls/Input/TextBox.cs) - 文本框

继承原生 `System.Windows.Controls.TextBox`，增加了清除命令绑定。

```csharp
public class TextBox : System.Windows.Controls.TextBox
{
    public TextBox()
    {
        // 绑定清除命令
        CommandBindings.Add(new CommandBinding(ControlCommands.Clear,
            (s, e) => { Clear(); }));
    }
}
```

### 配合 InfoElement 使用

```xml
<!-- 带标题和必填标记 -->
<hc:TextBox hc:InfoElement.Title="用户名"
            hc:InfoElement.Necessary="True"
            hc:InfoElement.Symbol="&#xe739;"
            hc:InfoElement.TitlePlacement="Top"
            Width="240"/>

<!-- 带水印 -->
<hc:TextBox hc:InfoElement.Placeholder="请输入用户名"/>
```

## 💧 [WatermarkTextBox.cs](../src/Shared/HandyControl_Shared/Controls/Input/WatermarkTextBox.cs) - 水印文本框

在 TextBox 基础上增加水印功能，当文本为空时显示提示文字。

```csharp
public class WatermarkTextBox : TextBox
{
    public static readonly DependencyProperty WatermarkProperty = DependencyProperty.Register(
        nameof(Watermark), typeof(object), typeof(WatermarkTextBox));

    public object Watermark
    {
        get => GetValue(WatermarkProperty);
        set => SetValue(WatermarkProperty, value);
    }

    protected override void OnGotFocus(RoutedEventArgs e)
    {
        base.OnGotFocus(e);
        // 聚焦时选中所有文本（便于快速修改）
        if (SelectionLength == 0)
            SelectAll();
    }
}
```

**使用：**

```xml
<hc:WatermarkTextBox Watermark="请输入搜索关键字..." Width="200"/>
```

## ✅ 数据验证机制

### ValidationRule 验证规则

HandyControl 提供两个内置验证规则，位于 [Tools/ValidationRule/](../src/Shared/HandyControl_Shared/Tools/ValidationRule/)。

#### [RegexRule.cs](../src/Shared/HandyControl_Shared/Tools/ValidationRule/RegexRule.cs) - 正则验证

```csharp
public class RegexRule : ValidationRule
{
    public string RegexPattern { get; set; }

    public override ValidationResult Validate(object value, CultureInfo cultureInfo)
    {
        var text = value?.ToString();
        if (string.IsNullOrEmpty(text))
            return new ValidationResult(false, "不能为空");

        if (RegexPattern != null && !Regex.IsMatch(text, RegexPattern))
            return new ValidationResult(false, "格式不正确");

        return ValidationResult.ValidResult;
    }
}
```

#### [NoBlankTextRule.cs](../src/Shared/HandyControl_Shared/Tools/ValidationRule/NoBlankTextRule.cs) - 非空验证

```csharp
public class NoBlankTextRule : ValidationRule
{
    public override ValidationResult Validate(object value, CultureInfo cultureInfo)
    {
        return string.IsNullOrWhiteSpace(value?.ToString())
            ? new ValidationResult(false, "不能为空")
            : ValidationResult.ValidResult;
    }
}
```

### 在绑定中使用验证

```xml
<hc:TextBox hc:InfoElement.Title="邮箱"
            Width="260">
    <hc:TextBox.Text>
        <Binding Path="Email" UpdateSourceTrigger="PropertyChanged">
            <Binding.ValidationRules>
                <validationRule:RegexRule RegexPattern="^[\w-\.]+@([\w-]+\.)+[\w-]{2,4}$"/>
            </Binding.ValidationRules>
        </Binding>
    </hc:TextBox.Text>
</hc:TextBox>
```

### 显示验证错误

配合 `InfoElement.ErrorMessage` 显示错误信息：

```xml
<hc:TextBox hc:InfoElement.ErrorMessage="{Binding (Validation.Errors)[0].ErrorContent,
    RelativeSource={x:Static RelativeSource.Self}}"/>
```

## 🎯 输入控件开发模式

### 模式 1：继承原生控件 + 命令绑定

适用于只需少量扩展的场景：

```csharp
public class TextBox : System.Windows.Controls.TextBox
{
    public TextBox()
    {
        CommandBindings.Add(new CommandBinding(ControlCommands.Clear,
            (s, e) => Clear()));
    }
}
```

### 模式 2：继承 Control + TemplatePart

适用于需要完全自定义视觉树的复合控件：

```csharp
[TemplatePart(Name = "PART_TextBox", Type = typeof(TextBox))]
[TemplatePart(Name = "PART_ButtonUp", Type = typeof(ButtonBase))]
[TemplatePart(Name = "PART_ButtonDown", Type = typeof(ButtonBase))]
public class NumericUpDown : Control
{
    public override void OnApplyTemplate()
    {
        base.OnApplyTemplate();

        _textBox = GetTemplateChild("PART_TextBox") as TextBox;
        _buttonUp = GetTemplateChild("PART_ButtonUp") as ButtonBase;
        _buttonDown = GetTemplateChild("PART_ButtonDown") as ButtonBase;

        // 绑定事件
        if (_buttonUp != null) _buttonUp.Click += (s, e) => Value += Increment;
        if (_buttonDown != null) _buttonDown.Click += (s, e) => Value -= Increment;
    }
}
```

### 模式 3：附加属性增强

无侵入式扩展现有控件：

```csharp
public static class InfoElement
{
    public static readonly DependencyProperty TitleProperty =
        DependencyProperty.RegisterAttached("Title", typeof(string), typeof(InfoElement),
            new PropertyMetadata(OnTitleChanged));

    private static void OnTitleChanged(DependencyObject d, DependencyPropertyChangedEventArgs e)
    {
        // 创建 TextBlock 并添加到控件的装饰层
    }
}
```

### 1. 表单布局推荐

```xml
    <hc:ComboBox hc:InfoElement.Title="角色"

                 Width="280">
        <ComboBoxItem Content="管理员"/>
        <ComboBoxItem Content="普通用户"/>
    </hc:ComboBox>
</StackPanel>
```

### 2. 数据绑定与验证

```csharp
// ViewModel
public class LoginViewModel : INotifyPropertyChanged, IDataErrorInfo
{
    public string Username { get; set; }
    public string Password { get; set; }

    public string this[string columnName] => columnName switch
    {
        nameof(Username) when string.IsNullOrWhiteSpace(Username) => "用户名不能为空",
        nameof(Password) when Password?.Length < 6 => "密码至少6位",
        _ => null
    };
}
```

### 3. 使用 InfoElement 统一表单样式

所有输入控件通过 `hc:InfoElement.Title` 获得一致的标签样式，无需手动添加 Label。
