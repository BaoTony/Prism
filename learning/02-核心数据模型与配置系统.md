# HandyControl 深度学习 - 核心数据模型与配置系统

## 📊 数据层架构概览

HandyControl 的数据层（[Data/](../src/Shared/HandyControl_Shared/Data/)）是整个控件的基石，提供了类型安全的数据结构、全局配置管理和核心枚举定义。

### 数据层设计原则

1. **强类型优先**：使用枚举和自定义类型避免魔法值
2. **不可变性**：数据类尽可能设计为不可变
3. **延迟初始化**：优化启动性能
4. **线程安全**：关键数据结构考虑并发访问

## 🎛️ 全局配置系统

### [HandyControlConfig.cs](../src/Shared/HandyControl_Shared/Data/HandyControlConfig.cs) - 配置中心

```csharp
namespace HandyControl.Data;

public class HandyControlConfig
{
    /// <summary>
    /// 当前语言设置
    /// </summary>
    public string Lang { get; set; }

    /// <summary>
    /// 时间轴动画帧率，默认60fps
    /// </summary>
    public int TimelineFrameRate { get; set; } = 60;
}
```

#### 配置项详解

| 属性 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `Lang` | `string` | `null` | 语言代码，如 "zh-CN", "en" |
| `TimelineFrameRate` | `int` | `60` | 动画帧率，影响所有时间相关动画 |

#### 使用示例

**程序启动时配置：**

```csharp
// App.xaml.cs
public partial class App : Application
{
    protected override void OnStartup(StartupEventArgs e)
    {
        base.OnStartup(e);
        
        // 配置 HandyControl
        var config = new HandyControlConfig
        {
            Lang = "zh-CN",
            TimelineFrameRate = 60
        };
        
        // 应用配置（内部实现）
        ConfigHelper.SetConfig(config);
    }
}
```

**运行时修改配置：**

```csharp
// 切换语言
var config = ConfigHelper.GetConfig();
config.Lang = "en";

// 修改动画帧率（需要重启应用才能完全生效）
config.TimelineFrameRate = 30;
```

#### 配置系统的内部实现

虽然 `HandyControlConfig` 本身很简单，但实际的配置管理通过 [ConfigHelper](../src/Shared/HandyControl_Shared/Tools/Helper/ConfigHelper.cs) 实现：

```csharp
public static class ConfigHelper
{
    private static HandyControlConfig _config;
    
    public static void SetConfig(HandyControlConfig config)
    {
        _config = config ?? throw new ArgumentNullException(nameof(config));
        // 应用语言设置
        if (!string.IsNullOrEmpty(config.Lang))
        {
            LangProvider.ChangeLang(config.Lang);
        }
    }
    
    public static HandyControlConfig GetConfig()
    {
        return _config ??= new HandyControlConfig();
    }
}
```

### [ValueBoxes.cs](../src/Shared/HandyControl_Shared/Data/ValueBoxes.cs) - 值装箱优化

```csharp
public static class ValueBoxes
{
    // 预装箱的常用值
    public static readonly object TrueBox = true;
    public static readonly object FalseBox = false;
    public static readonly object ZeroBox = 0;
    
    // 工厂方法
    public static object BooleanBox(bool value) => value ? TrueBox : FalseBox;
    
    public static object IntBox(int value)
    {
        switch (value)
        {
            case 0: return ZeroBox;
            default: return value;
        }
    }
}
```

**为什么需要这个？**

WPF 的依赖属性默认值是 `object` 类型，每次设置都会导致值类型装箱：

```csharp
// ❌ 不好的做法：每次都装箱
new PropertyMetadata(false);  // 每次 false 都会装箱

// ✅ 好的做法：使用预装箱的值
new PropertyMetadata(ValueBoxes.FalseBox);  // 复用同一个对象
```

### [DisposableObject.cs](../src/Shared/HandyControl_Shared/Data/DisposableObject.cs) - 可释放对象基类

```csharp
public abstract class DisposableObject : IDisposable
{
    private bool _disposed;

    protected virtual void Dispose(bool disposing)
    {
        if (!_disposed)
        {
            if (disposing)
            {
                // 释放托管资源
                DisposeManagedResources();
            }
            
            // 释放非托管资源
            DisposeUnmanagedResources();
            
            _disposed = true;
        }
    }

    protected virtual void DisposeManagedResources() { }
    protected virtual void DisposeUnmanagedResources() { }

    public void Dispose()
    {
        Dispose(true);
        GC.SuppressFinalize(this);
    }

    ~DisposableObject()
    {
        Dispose(false);
    }
}
```

**使用场景：**
- 包含非托管资源的类（GDI+ 对象、句柄等）
- 需要显式释放的资源密集型对象

**示例：**

```csharp
public class GifImageAnimator : DisposableObject
{
    private Image _image;
    
    protected override void DisposeManagedResources()
    {
        _image?.Dispose();
        _image = null;
    }
}
```

```csharp
        => new OperationResult<T> { Success = false, Message = message, Exception = ex };
}
```

## 🎨 数据驱动的设计理念

### 1. 枚举优于字符串

**❌ 不好的做法：**
```csharp
// 使用魔法字符串
button.SetProperty("InfoType", "Error");
```

```csharp
// 使用强类型枚举
Growl.Error("发生错误");

Growl.Info(new GrowlInfo { InfoType = InfoType.Error, Message = "发生错误" });
```

```csharp
Growl.Show("消息", true, 3000, ShowAnimation.Fade, true, null, 30);
```

```csharp
Growl.Info(new GrowlInfo
```

```csharp
public OperationResult SaveData(DataModel data)
```
